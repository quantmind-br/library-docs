# 06. Sharing

Methods for exposing a local TabbyAPI instance externally without a custom domain or reverse proxy.

## Ngrok

Recommended method — fastest throughput, but free tier has limits.

1. Sign up and install ngrok per [their website](https://ngrok.com/docs/getting-started/).
   - Windows: use `winget install --id=Ngrok.Ngrok -e` (chocolatey isn't pre-installed).
2. Start your TabbyAPI instance.
3. In a separate terminal, run `ngrok http 5000` (or your TabbyAPI port).
4. Copy the public URL and share it.

## Cloudflared

Free tunneling by Cloudflare — no URL restrictions, but slower client throughput.

1. Download the cloudflared binary from [their releases](https://github.com/cloudflare/cloudflared/releases).
2. Open a terminal where cloudflared is located.
3. Start your TabbyAPI instance.
4. Run `./cloudflared tunnel --url 127.0.0.1:5000`.
5. Copy the provided HTTPS URL and share it.

## Tailscale

WireGuard-based mesh VPN — private LAN accessible from anywhere.

> [!warning]
> This does not expose your instance to the public internet. Use Ngrok or Cloudflared for that.

1. Set TabbyAPI IP to `0.0.0.0` (required for external access).
2. Sign up at [Tailscale](https://tailscale.com/) and install the client.
3. Connect both host and client machines to your Tailscale account.
4. Open the Tailscale system tray icon and note the host device IP (identified by hostname).
5. Access TabbyAPI at `<tailscale IP>:5000` while connected to your tailnet.

# Mappable actions

Actions can be mapped to any key press or mouse action via `map` and `mouse_map` directives in `kitty.conf`. See [[025-mapping]] for keyboard mapping details and the default shortcut links for each action.

Browse and trigger actions interactively with [[007-kittens-command-palette]].

See [[037-conf]] for the `include` directive to load action definitions from other files.

# Contributing

## Reporting Issues

Found a bug or have a feature request? Open an issue on the relevant repository.

## Community Standards

Be respectful on all forums: GitHub discussions, Discord, etc.

## Types of Contributions

All contributions are appreciated:
- Code
- Documentation
- Bug reports
- Monetary support

## Licensing

All Dank Linux projects are licensed under the MIT License. By contributing, you agree to license your contributions under the same license.

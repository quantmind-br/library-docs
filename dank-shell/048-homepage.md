# Modern Desktop for Wayland Compositors

DankMaterialShell (DMS) is a desktop shell for Wayland compositors (niri, Hyprland, MangoWC, Sway, labwc, MiracleWM) with dynamic Material Design 3 theming, smooth animations, and integrated system utilities.

## Components

- **DankDash** — Overview dashboard with media controls, weather, calendar, system info
- **Launcher** — Application launcher with filesystem search
- **Control Center** — Configurable system settings and quick toggles
- **System Monitor** — Real-time process and system metrics
- **Widget Customization** — Personalize desktop experience
- **Plugins** — Extend with new widgets and launcher features
- **Dank Install** — One-line automated setup installer
- **Dank GOP** — Stateless CPU/GPU/memory/disk/network monitor
- **Dank Greeter** — Aesthetic greetd greeter
- **Dank Search** — Blazing fast filesystem search

## Beautiful by Default

Dynamic theming powered by matugen extracts colors from your wallpaper.

- Material Design 3 color schemes
- Automatic theming for system applications
- Automatic light/dark mode
- Smooth animations throughout

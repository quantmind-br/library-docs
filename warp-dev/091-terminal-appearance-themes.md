Customize Warp's terminal appearance using the built-in theme picker, create themes from background images, and sync with OS light/dark modes.

## Theme Picker

Access via **Settings** > **Appearance** > click the Custom Themes box.

1. Select a theme — Warp updates immediately.
2. Press the checkmark to save, or X to revert.

> [!note]
> Theme settings persist across sessions.

## Theme Creator

Automatically generate a theme from a background image.

1. Go to **Settings** > **Appearance** > **Themes** (or search "Open theme picker" in the Command Palette).
2. Click **+** in the theme picker.
3. Upload the image and select a background color.
4. Click "Create Theme".

## OS Theme Sync

Sync Warp's theme with the OS light/dark modes.

1. Open **Settings** > **Appearance**.
2. Toggle "Sync with OS".
3. Select a theme for light mode and a theme for dark mode.

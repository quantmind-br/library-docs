## Hyprlauncher

First-party multipurpose versatile launcher/picker for Hyprland. See [[054-hypr-ecosystem-hyprlauncher|hyprlauncher]].

## Wofi

GTK-based customizable launcher for Wayland. [SourceHut](https://hg.sr.ht/~scoopta/wofi)

## Rofi

Window switcher, application launcher, and `dmenu` replacement. Supports Wayland since 2025. [GitHub](https://github.com/davatorium/rofi)

## bemenu

Wayland-native replacement for dmenu. [GitHub](https://github.com/Cloudef/bemenu)

## HyprTile

Mega-Launcher for Hyprland. Tiny, easy to use with app grid, flexible per-app configuration, integrated music search, notes system, screenshot and screenrecording (full screen or selected area), system monitor, volume control, starfield background, and nice optics. [hyprtile.org](https://hyprtile.org/).

## fuzzel

Application launcher for wlroots-based Wayland compositors, similar to rofi's `drun` mode. [Codeberg](https://codeberg.org/dnkl/fuzzel)

## tofi

Extremously fast and simple yet highly customizable dmenu/rofi replacement for wlroots-based Wayland compositors. Can get on screen within a single frame when configured correctly. [GitHub](https://github.com/philj56/tofi)

## Emacs

If running an emacs server, can use Emacs as launcher. Config examples: [DistroTube's app-launchers.el](https://gitlab.com/dwt1/configuring-emacs/-/blob/main/07-the-final-touches/scripts/app-launchers.el?ref_type=heads) or [SebastienWae/app-launcher](https://github.com/SebastienWae/app-launcher).

## Anyrun

Wayland-native krunner-like runner with customizability in mind. Modular and extensible through plugins. Can be used as app launcher with its Applications Plugin. [GitHub](https://github.com/anyrun-org/anyrun)

## Walker

Extensible Wayland-native runner with built-in modules (applications, runner, hyprland windows, websearch [as of 2024-03-15]). Can run as service for faster startups. [GitHub](https://github.com/abenz1267/walker)

## Vicinae

C++ and Qt native launcher focused on Wayland. Many built-in modules, runs as background server. Supports raycast extensions via compatibility layer. [GitHub](https://github.com/vicinaehq/vicinae)

For more launchers, see [awesome-hyprland](https://github.com/hyprland-community/awesome-hyprland#runners-menus-and-application-launchers).

# 02. Server Options

TabbyAPI uses `config.yml` as the primary configuration method, with CLI arguments to override config values.

> [!note]
> For the latest `config.yml` docs, see comments in `config_sample.yml`.

CLI arguments override `config.yml` settings and behave differently from typical programs — especially with booleans. Example: if `gpu_split_auto` is `True` in config, override with `--gpu_split-auto False`.

Some config options are too complex for CLI representation and are excluded from the argparser.

All options have descriptive comments in `config_sample.yml`. This page is a reference when comments aren't enough.

## Networking Options

| Config Option          | Type (Default)         | Description                                                                                                             |
| ---------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| host                   | String (127.0.0.1)     | IP address for hosting TabbyAPI                                                                                         |
| port                   | Int (5000)             | TCP port for TabbyAPI                                                                                                   |
| disable_auth           | Bool (False)           | Disables API authentication                                                                                             |
| disable_fetch_requests | Bool (False)           | Disables fetching external content (e.g., images from URLs)                                                             |
| send_tracebacks        | Bool (False)           | Sends server tracebacks to client. Not recommended when sharing the instance.                                           |
| api_servers            | List[String] (["OAI"]) | API servers to enable. Values: `"OAI"`, `"Kobold"`                                                                      |

## Logging Options

| Config Option         | Type (Default) | Description                                            |
| --------------------- | -------------- | ------------------------------------------------------ |
| log_prompt            | Bool (False)   | Logs prompts to the console                            |
| log_generation_params | Bool (False)   | Logs request generation options to the console         |
| log_requests          | Bool (False)   | Logs request URL, body, and headers to the console     |

## Sampling Options

For sampling overrides, not samplers themselves. See [[008-docs-08.-sampler-overrides|Sampler Overrides]].

| Config Option   | Type (Default) | Description                                                               |
| --------------- | -------------- | ------------------------------------------------------------------------- |
| override_preset | String (None)  | Start the given sampler override preset from the `sampler_overrides` folder |

## Developer Options

Experimental flags — may be removed at any time.

| Config Option             | Type (Default)                 | Description                                                                                                                                     |
|---------------------------|--------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| unsafe_launch             | Bool (False)                   | Skips dependency checks on startup. For debugging only.                                                                                         |
| disable_request_streaming | Bool (False)                   | Forcefully disables streaming requests                                                                                                          |
| realtime_process_priority | Bool (False)                   | Sets process priority to "Realtime". Requires admin/sudo; otherwise set to highest userland priority.                                            |
| seqlog                    | Bool (False)                   | Enable logging to Seq server                                                                                                                    |
| seqlog_server_url         | String (http://localhost:5341) | Seq server URL and port                                                                                                                         |
| seqlog_api_key            | String (None)                  | API key for Seq server, if required                                                                                                             |

## Model Options

Most options apply only on initial load (ephemeral). Add option names to `use_as_default` to persist them.

| Config Option         | Type (Default)                   | Description                                                                                                                                                                                                                    |
| --------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| model_dir             | String ("models")                | Directory to look for models. Persisted across load requests.                                                                                                                                                                  |
| inline_model_loading  | Bool (False)                     | Enables model switching via the `model` argument in generation requests. See [[003-docs-03.-usage#inline-loading|Inline Loading]].                                                                                             |
| use_dummy_models      | Bool (False)                     | Sends a dummy OAI model card on `/v1/models`. For clients enforcing specific OAI models. Persisted across load requests.                                                                                                       |
| dummy_model_names     | List[String] (["gpt-3.5-turbo"]) | Dummy names sent on model endpoint requests. Persisted across load requests.                                                                                                                                                    |
| model_name            | String (None)                    | Folder name of a model to load. Below parameters apply only if this is set.                                                                                                                                                     |
| use_as_default        | List[String] ([])                | Keys to use by default on model load. E.g., `cache_mode` here makes every model load with that value unless overridden by the API request. Also applies to the `draft` sub-block.                                               |
| max_seq_len           | Float (None)                     | Maximum sequence length (max context length). Uses `config.json` value if not specified.                                                                                                                                        |
| tensor_parallel       | Bool (False)                     | Enables tensor parallelism. Falls back to autosplit if GPU split isn't provided. `gpu_split_auto` is ignored when enabled.                                                                                                      |
| gpu_split_auto        | Bool (True)                      | Automatically splits the model across GPUs. Manual `gpu_split` is ignored when enabled.                                                                                                                                         |
| autosplit_reserve     | List[Int] ([96])                 | Empty VRAM to reserve during autosplit, in MB per GPU used.                                                                                                                                                                    |
| gpu_split             | List[Float] ([])                 | GB values to split a model between GPUs.                                                                                                                                                                                       |
| rope_scale            | Float (1.0)                      | RoPE scale adjustment (compress_pos_emb). Ignored if the model has YaRN support.                                                                                                                                               |
| rope_alpha            | Float (None)                     | RoPE alpha adjustment. Auto-calculated from `max_seq_len` if blank. Ignored if the model has YaRN support.                                                                                                                      |
| cache_mode            | String ("FP16")                  | K/V cache mode. Options: FP16, Q8, Q6, Q4.                                                                                                                                                                                    |
| cache_size            | Int (max_seq_len)                | K/V cache size. If using CFG, set to `2 * max_seq_len`.                                                                                                                                                                        |
| chunk_size            | Int (2048)                       | Tokens per ingestion chunk. Lower values reduce VRAM at the cost of ingestion speed.                                                                                                                                            |
| max_batch_size        | Int (None)                       | Maximum concurrent prompts. Auto-adjusted based on cache size.                                                                                                                                                                 |
| prompt_template       | String (None)                    | Jinja2 chat template name. Must be in the `templates` directory.                                                                                                                                                               |
| vision                | Bool (False)                     | Enable vision support for the model (if available).                                                                                                                                                                            |

## Draft Model Options

Sub-block of Model Options. Same ephemeral/persistence rules apply.

| Config Option    | Type (Default)    | Description                                                                                |
| ---------------- | ----------------- | ------------------------------------------------------------------------------------------ |
| draft_model_dir  | String ("models") | Directory to look for draft models. Persisted across load requests.                        |
| draft_model_name | String (None)     | Folder name of a draft model to load.                                                      |
| draft_rope_scale | Float (1.0)       | RoPE scale value for the draft model.                                                      |
| draft_rope_alpha | Float (1.0)       | RoPE alpha for the draft model. Leave blank for auto-calculation.                          |
| draft_cache_mode | String ("FP16")   | Cache mode for the draft model. Options: FP16, Q8, Q6, Q4.                                 |
| draft_gpu_split  | List[Float] ([])  | GB values to split a draft model between GPUs.                                             |

## Lora Options

Sub-block of Model Options. Same ephemeral/persistence rules apply.

| Config Option | Type (Default)   | Description                                                  |
|---------------|------------------|--------------------------------------------------------------|
| lora_dir      | String ("loras") | Directory to look for LoRAs. Persisted across load requests. |
| loras         | List[loras] ([]) | List of LoRA objects to apply. Each contains `name` and `scaling`. |
| name          | String (None)    | Folder name of a LoRA to load. Element of the `loras` key.   |
| scaling       | Float (1.0)      | Application weight on the parent model. E.g., 0.9 reduces LoRA influence. Element of the `loras` key. |

## Embeddings Options

Most options apply only on initial embedding model load (ephemeral).

| Config Option        | Type (Default)    | Description                                                                                                                  |
| -------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| embedding_model_dir  | String ("models") | Directory to look for embedding models. Persisted across load requests.                                                      |
| embeddings_device    | String ("cpu")    | Device for embedding model. Options: cpu, cuda, auto. Persisted across load requests.                                        |
| embedding_model_name | String (None)     | Folder name of an embedding model to load using infinity-emb.                                                                |

# Codex app

Focused desktop experience for working on Codex threads in parallel, with built-in worktree support, automations, and Git functionality.

> [!info]
> Included with ChatGPT Plus, Pro, Business, Edu, and Enterprise. See [[075-pricing|what's included]].

## Getting started

Available on macOS and Windows. Most features work on both platforms; platform-specific exceptions are noted in relevant docs.

1. **Download and install**
   - [Download for macOS or Windows](https://get.microsoft.com/installer/download/9PLM9XGG6VKS?cid=website_cta_psi) (choose Intel build for Intel-based Macs).
   - [Get notified for Linux](https://openai.com/form/codex-app/)
2. **Open and sign in**
   - Sign in with ChatGPT account or OpenAI API key.
   - API key sign-in may disable some functionality such as cloud threads.
3. **Select a project**
   - Choose a project folder for Codex to work in. Past projects from app, CLI, or IDE extension appear automatically.
4. **Send your first message**
   - Make sure **Local** is selected, then ask anything about the project or computer.
   - Example prompts:
     - "Tell me about this project"
     - "Build a classic Snake game in this repo" (grid movement, growing snake, food spawn, score, game-over, restart; reuse existing tooling; minimal UI)
     - "Find and fix bugs in my codebase with minimal, high-confidence changes" (reproduce, localize, fix, prove)
   - Explore [[039-workflows|Codex use cases]] or read [[029-learn-best-practices|best practices]] for more.

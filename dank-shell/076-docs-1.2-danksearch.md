`dsearch` is a native file system search tool with configurable indexes and a CLI + REST API for searching files with various parameters.

DankSearch integrates with DankMaterialShell's Spotlight launcher, providing:
1. Fast indexed filesystem search from the launcher
2. CLI access for scripts and automation
3. REST API for external integrations

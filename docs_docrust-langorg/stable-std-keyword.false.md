A value of type [`bool`](https://doc.rust-lang.org/stable/std/primitive.bool.html "primitive bool") representing logical **false**.

`false` is the logical opposite of [`true`](https://doc.rust-lang.org/stable/std/keyword.true.html).

See the documentation for [`true`](https://doc.rust-lang.org/stable/std/keyword.true.html) for more information.

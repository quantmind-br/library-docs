Split panes divide a tab into multiple independent terminal sessions arranged as rectangles.

## Keyboard shortcuts

| Action | Shortcut |
|---|---|
| Split right | `CMD-D` |
| Split down | `SHIFT-CMD-D` |
| Split any direction | Right-click a pane |
| Activate previous pane | `CMD-[` |
| Activate next pane | `CMD-]` |
| Navigate with triangle marker | `OPT-CMD-ARROW` |
| Maximize pane | `CMD-SHIFT-ENTER` |
| Close active pane | `CMD-W` |

## Drag and drop

- Click and drag a pane's header to reorder within a tab.
- Drag a pane to the tab bar to move it to another tab or convert it into a new tab.

## CTRL-TAB behavior

`CTRL-TAB` activates previous/next [[127-terminal-windows-tabs|tab]] by default. Configure it to cycle through recent sessions (including split panes) in **Settings** > **Features** > **Keys** > **Ctrl-Tab behavior**.

# Getting Started

The installer adds the appropriate repository (AUR, COPR, OBS, or PPA) for your distro; updates are managed through your normal package manager.

> [!tip]
> If you install DMS directly from packages, run `dms setup` to generate starter compositor and terminal configs (niri/Hyprland only). Other compositors (sway, MangoWC, labwc) are supported—see [[006-docs-1.2-dankmaterialshell-installation#post-install|manual configuration]].

Manual installation is also supported. See the installation section for each component.

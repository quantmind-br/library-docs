## Symbol lookup errors

Symptom: `symbol lookup error: undefined symbol` or `error while loading shared libraries` or silent crashes.

Cause: Mismatched library stack after building Hyprland yourself.

> [!warning]
> Use packages instead of building yourself. When building, rebuild **all** hypr* components together — you cannot mix packages and repos. Arch users: `-git` packages count as building yourself.

Build order for hypr* stack:

```
hyprland-protocols → hyprwayland-scanner → hyprutils → hyprgraphics → hyprlang → hyprcursor → aquamarine → xdg-desktop-portal-hyprland → hyprwire → hyprtoolkit → hyprland
```

Other hyprapps (hyprlock, hyprsunset, etc.) can be built in any order after hyprland.

> [!danger]
> Never symlink different `.so` versions together — this causes memory bugs and crashes.

## My apps are pixelated

Apps running through XWayland cannot scale by fractional amounts.

Fix: Force native Wayland mode — see [[002-getting-started-master-tutorial#force-apps-to-use-wayland]].

If native Wayland is not available, see [[050-configuring-xwayland]].

## Nothing renders / screen is empty / crash on opening first app

**Cause 1:** Themes not set up properly → apps crash. Fix: use `qt6ct` (Qt) and `nwg-look` (GTK).

**Cause 2:** Very old PC. Fix: compile with `LEGACY_RENDERER` — see [[001-getting-started-installation]].

For more crash info, see [[032-crashes-and-bugs]].

## External monitor blank / no signal (laptop)

**Nvidia:** Update to drivers 525.60.11 or later.

**Limited hardware (iGPU, USB-C, USB Hubs):** Set `env = AQ_NO_MODIFIERS,1`. Check DRM log for `Requested display configuration exceeds system DDB limitations`.

**Other fixes:**

1. Use only the external monitor: `AQ_DRM_DEVICES=/dev/dri/card1` forces dGPU only (laptop screen will be disabled).
2. Switch BIOS to dGPU-only for all outputs (high battery usage).

> [!note]
> These are highly model-specific. A USB-C to HDMI adapter may route through iGPU.

## How do I screenshot?

**Option 1:** `grim` + `slurp`

```bash
grim -g "$(slurp)"  # select region, saves to ~/Pictures/
grim -g "$(slurp -d)" - | wl-copy  # direct to clipboard
```

For a complete utility, see [Grimblast](https://github.com/hyprwm/contrib).

**Option 2:** [Hyprshot](https://github.com/Gustash/Hyprshot) or [Hyprcap](https://github.com/alonso-herreros/hyprcap).

**Option 3:** `flameshot` — many built-in features (paintbrush, lines, shapes).

> [!warning]
> Flameshot was built for X and has many Wayland issues. HiDPI and multi-monitor users have mixed results.

Flameshot window rules:

```ini
windowrule = match:class flameshot, no_anim
windowrule = match:class flameshot, float
windowrule = match:class flameshot, move 0 0
windowrule = match:class flameshot, pin
windowrule = match:class flameshot, no_initial_focus
windowrule = match:class flameshot, monitor 1
bind = ..., exec, XDG_CURRENT_DESKTOP=sway flameshot gui
```

For video recording: [wf-recorder](https://github.com/ammen99/wf-recorder), [wl-screenrec](https://github.com/russelltg/wl-screenrec), or [OBS Studio](https://obsproject.com/).

## How heavy is this?

## My monitor no worky

Try changing the video mode in config. If preferred mode fails, try a lower one. List all modes:

```bash
wlr-randr --dryrun
```

## My monitor has flickering brightness with VRR

Change VRR option to `2` (fullscreen only) — brightness depends on refresh rate on some monitors, and rapid rate changes cause flickering.

If VRR always-on is needed, mitigate flickering by changing the VRR range in the monitor's EDID. See [ArchWiki](https://wiki.archlinux.org/title/Kernel_mode_setting#Forcing_modes_and_EDID).

## How do I update?

```bash
git pull && make all && sudo make install
```

AUR (`hyprland-git`): cleanbuild to update. Paru has been problematic — use Yay.

## How do I screen lock?

Use a Wayland-compatible locking utility (e.g. `swaylock`). Note: these do not prevent tty-changing via Ctrl+Alt+F1...F7.

## How do I change my mouse cursor?

See [[006-hypr-ecosystem-hyprcursor]].

1. Set GTK cursor with [nwg-look](https://github.com/nwg-piotr/nwg-look).
2. Add `exec-once=hyprctl setcursor [THEME] [SIZE]` to config and restart Hyprland.

For flatpak: `flatpak override --filesystem=~/.themes:ro --filesystem=~/.icons:ro --user` and put themes in both `/usr/share/themes` and `~/.themes`, icons in both `/usr/share/icons` and `~/.icons`.

For Qt, Hyprland exports `XCURSOR_SIZE=24`. Override with `env = XCURSOR_SIZE,<value>`.

Also: `gsettings set org.gnome.desktop.interface cursor-theme 'theme-name'` or add to `exec-once=`.

Without a GTK settings editor, edit `~/.config/gtk-4.0/settings.ini` and `~/.gtkrc-2.0` per [XDG spec](https://wiki.archlinux.org/title/Cursor_themes#Configuration).

## How do I autostart my favorite apps?

Use window rules to assign apps to workspaces. Start silently (no flickering):

```ini
exec-once = [workspace 1 silent] kitty
exec-once = [workspace 1 silent] subl
exec-once = [workspace 3 silent] mailspring
exec-once = [workspace 4 silent] firefox
```

## Move workspaces to new monitor when plugged in

Add to `hyprland.conf`:

```ini
exec-once = handle_monitor_connect.sh
```

```sh
#!/bin/sh
handle() {
  case $1 in monitoradded*)
    hyprctl dispatch moveworkspacetomonitor "1 1"
    hyprctl dispatch moveworkspacetomonitor "2 1"
    hyprctl dispatch moveworkspacetomonitor "4 1"
    hyprctl dispatch moveworkspacetomonitor "5 1"
  esac
}
socat - "UNIX-CONNECT:$XDG_RUNTIME_DIR/hypr/${HYPRLAND_INSTANCE_SIGNATURE}/.socket2.sock" | while read -r line; do handle "$line"; done
```

This moves workspaces 1, 2, 4, and 5 to monitor 1. Requires `socat`.

## Apps take a really long time to open

Add to `~/.config/hypr/hyprland.conf`:

```ini
exec-once = dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
```

If portals launch before this executes, use a script:

```bash
#!/usr/bin/env bash
sleep 4
killall -e xdg-desktop-portal-hyprland
killall xdg-desktop-portal
/usr/lib/xdg-desktop-portal-hyprland &
sleep 4
/usr/lib/xdg-desktop-portal &
```

Launch with `exec-once`. Adjust sleep durations.

## How to disable middle-click paste?

Set `misc:middle_click_pase = false` to disable globally. Firefox has a separate built-in way to emulate this — disable in browser settings.

## How do I make Hyprland draw as little power as possible on my laptop?

- `decoration:blur:enabled = false` and `decoration:shadow:enabled = false` — disable battery-hungry effects.
- `misc:vfr = true` — lowers frames when nothing is on-screen.

## Screenshot utilities won't work with multiple screens

For Flameshot and similar programs with limited Wayland support, add window rules:

```ini
windowrule = match:title flameshot, float true
windowrule = match:title flameshot, move 0 0
windowrule = match:title flameshot, suppress_event fullscreen
```

## I cannot bind SUPER as my mod key on my laptop

Many laptops toggle `SUPER` between single-press and hold mode (padlock icon on key).

1. Install and run `wev`, press `SUPER`.
2. If key press followed by instant release → single-press mode.
3. Fix: press `FN+SUPER`. Verify in `wev` — holding `SUPER` should not show instant release.
4. If `FN+SUPER` does not work, consult laptop manual.

## My VM doesn't receive keybinds I set in Hyprland

Hyprland takes precedence over VM keybinds. Fix: create a passthrough submap.

```ini
bind = MOD,KEY,submap,passthru
submap = passthru
bind = SUPER,Escape,submap,reset
submap = reset
```

Set `MOD` and `KEY` to desired values. Press the combo to enter passthrough mode where Hyprland ignores keybinds. `SUPER+Escape` exits.

## Drop-down/pop-up windows disappear or don't open at cursor position

In apps like Steam or VSCode, pop-ups may disappear on hover. Fix with window rules.

1. Find title and class: `sleep 3 && hyprctl clients`, then open the pop-up.
2. If disappears on hover:

   ```ini
   windowrule = stay_focused, match:class CLASS, match:title TITLE
   ```

   > [!warning]
   > Cannot click main UI until pop-up is interacted with.

3. If disappears immediately:

   ```ini
   windowrule = min_size 1 1, match:class CLASS, match:title TITLE
   ```

4. If doesn't open at cursor position (XWayland only):

   ```ini
   windowrule = move cursor_x cursor_y, match:class CLASS, match:title TITLE
   ```

## Steam's file picker no worky

Steam needs `xdg-desktop-portal-gtk` to show the desktop file picker.

## Workspaces or clients disappearing / monitor dispatchers cause crashes

A kernel bug creates a phantom monitor (`Unknown-1`), causing various issues.

Check detected monitors: `hyprctl monitors`

Workaround in `hyprland.conf`:

```ini
monitor = Unknown-1,disabled
```

## I get a .so file missing error on launch

With `-git` packages: ABI-breaking updates are common.

> [!danger]
> Do NOT symlink different .so versions — this causes crashes.

Fix: remove all hypr* `-git` packages and reinstall. With yay: `CleanBuild` every package. With paru: manually clear `~/.cache/paru` of hypr* packages.

If not using `-git` packages: distro packaging error — report to your distro.

## My cursor is a hyprland icon

No hyprcursor theme or XCursor theme is installed. Install a cursor theme.

## Hyprwinwrap not visible through blurred windows

Side effect of `decoration:blur:new_optimizations`. Two options:

1. Set `decoration:blur:new_optimizations = false` — exact same appearance, slight performance cost.
2. Set `decoration:blur:ignore_opacity = false` — different appearance, original performance.

## I can't create Discord binds

Likely cause: `env = ELECTRON_OZONE_PLATFORM_HINT,wayland` in config.

Try: `ELECTRON_OZONE_PLATFORM_HINT= discord`

> [!warning]
> This runs Discord under XWayland.

If it works, edit the Discord `.desktop` entry in `/usr/share/applications/`: duplicate it, change `Exec` to `Exec=env ELECTRON_OZONE_PLATFORM_HINT= /usr/bin/discord`, optionally rename to `DiscordX`.

## Fullscreen applications/Steam games open with secondary monitor's resolution

Default X11 monitor is not your primary. Fix:

```ini
exec-once=xrandr --output [MONITOR_ID] --primary
```

Replace `[MONITOR_ID]` with your main monitor (e.g. `DP-3`). Find ID: `hyprctl monitors`.

This sets the default X11 monitor for all X11 applications to your main monitor.

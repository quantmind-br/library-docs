> [!info]
> This page documents global flags shared by `firectl billing notification-settings get` and `firectl billing notification-settings update`. No command-specific flags are available.

## Global flags

| Flag | Type | Description |
|------|------|-------------|
| `-a`, `--account-id` | string | Fireworks account ID. Defaults to `~/.fireworks/auth.ini`. |
| `--api-key` | string | API key for authentication. |
| `-p`, `--profile` | string | fireworks auth and settings profile to use. |

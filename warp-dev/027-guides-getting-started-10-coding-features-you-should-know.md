You can code directly in Warp. Here are 10 core features to get started:

1. **Search for Files** — Open the Command Palette (`Cmd+P` / `Ctrl+Shift+P`), then press `Cmd+O` / `Ctrl+O` to search and open any file — no need to `cd` around or remember paths.

2. **Tabbed File Viewer** — Files open in tabs rather than split panes, keeping your workspace clean while allowing quick switching between files.

3. **Full Editor Support** — Edit code directly inside Warp. Click and type, or use familiar shortcuts for highlight, copy, paste, and undo.

4. **Find and Replace** — Supports regular expressions, multi-cursor editing, replace-all, and preserve-case rules for fast refactoring.

5. **Syntax Highlighting** — Appears in agent-generated diffs and the file editor view for dozens of languages and frameworks.

6. **Linked File References** — When the agent references a file, it links to the exact line of code. Clicking opens that file at that line inside Warp.

   > [!tip]
   > In **Settings → Features**, set Warp as your default editor for file links so they open directly in Warp.

7. **Code Review Panel** — A dedicated panel summarizing all files and diffs touched by an agent. Review, approve, or edit changes inline and reference diffs in your next prompt.

8. **Code Snippet References** — When Warp explains something about your codebase, it surfaces the exact code snippet. Attach that snippet as fresh context for your next prompt to keep token usage lean.

9. **Codebase Indexing** — Warp automatically indexes repositories for faster, more context-aware responses — easier summaries, bug fixes, and intelligent refactors.

10. **File Tree View** — Click the file-tree icon to browse your entire repo and open any file with a single click.

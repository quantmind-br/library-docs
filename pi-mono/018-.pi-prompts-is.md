# Issue Investigation

Analyze GitHub issue(s): $ARGUMENTS

## Process

1. Add `inprogress` label via GitHub CLI before analysis. If label fails, report and continue.
2. Read issue in full (all comments, linked issues/PRs).
3. **Do not trust analysis in the issue.** Independently verify behavior.

## For Bugs

- Ignore root cause analysis in issue (likely wrong)
- Read all related code files in full (no truncation)
- Trace code path to identify actual root cause
- Propose a fix

## For Feature Requests

- Do not trust implementation proposals without verification
- Read all related code files in full (no truncation)
- Propose most concise implementation approach
- List affected files and changes needed

> [!warning]
> Do NOT implement unless explicitly asked. Analyze and propose only.

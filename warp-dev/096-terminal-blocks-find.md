Search for text across all blocks or within a specific block, from the bottom up.

## How to Access

- `CMD-F` opens the find view, scoped to the current pane.
- In the find modal: enable regex, search a selected block, or toggle case-sensitive search.

## How it Works

Since command outputs are contained within blocks, you can still use the input editor while find is active.

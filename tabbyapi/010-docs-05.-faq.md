# 05. FAQ

## What OS is supported?

Windows and Linux.

## How do I use this API?

Start scripts and `config.yml` guide new users. See [[003-docs-03.-usage|Usage]] for API details, [[011-docs-09.-community-projects|Community Projects]] for UIs, and the [Discord Server](https://discord.gg/sYQxnuD7Fj) for questions.

## How do I interface with the API?

Use the autogenerated docs: [OpenAI](https://theroyallab.github.io/tabbyAPI) and [Kobold](https://theroyallab.github.io/tabbyAPI/kobold) servers.

## What models does TabbyAPI run?

TabbyAPI uses Exllamav2 as its inference backend. Supported formats:

- Exl2 (highly recommended)
- GPTQ
- FP16 (via Exllamav2's loader)

## Exllamav2 `ImportError: DLL load failed while importing exllamav2_ext`

1. Verify the wheel matches your Python and CUDA versions. Ensure you're in a venv or conda environment.
2. If prerequisites are correct, clear the torch cache (mismatching `exllamav2_ext`):
   - Windows: `C:\Users\<User>\AppData\Local\torch_extensions\torch_extensions\Cache`
   - Linux: `~/.cache/torch_extensions`
   - Delete any `exllamav2_ext` folder in the Python subdirectories.
3. Restart TabbyAPI.

# Audible Terminal Bell

Enable an audible terminal bell (disabled by default) triggered by CLI tools (e.g., `ping -a`).

### Enable

- **Settings** → **Features** → **Terminal** → enable **Audible terminal bell**
- [[101-terminal-command-palette|Command Palette]] → "Enable/Disable Audible Terminal Bell"

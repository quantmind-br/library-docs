# Setup

The `dms setup` command generates default configuration files for your compositor (niri or Hyprland). It only writes files that don't already exist or are empty, so it won't clobber existing customizations.

## Usage

- `dms setup` (no arguments) — deploys all defaults at once
- Individual subcommands — deploy specific configs

## home-manager Users

If you manage niri or Hyprland config through home-manager, use individual subcommands to avoid conflicts with your declarative config. The niri home-manager module's `niri.includes` option references the same files under `~/.config/niri/dms/`. See the [[010-docs-dankmaterialshell-nixos-flake#config-includes|niri integration docs]] for the full list.

**Example**: Handle keybinds through the niri home-manager module but want DMS defaults for colors and layout — use only the specific subcommands for those pieces.

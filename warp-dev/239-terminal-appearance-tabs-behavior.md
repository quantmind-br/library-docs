# Tabs Behavior

Customize tab indicators, tab bar visibility, and close button position.

## Tab Indicators

Visual cues in the tab bar for: maximized pane, synchronized panes/tabs, and commands that exited with an error.

### Toggle

- **Settings** → **Appearance** → **Tabs** → toggle **Show tab indicators**
- [[101-terminal-command-palette|Command Palette]] → search "Tab indicators"

## Tab Bar

Provides navigation between open tabs. Visible by default in windowed mode; hidden in fullscreen (hover near the top to reveal).

### Configure

- **Settings** → **Appearance** → **Tabs** → **Show the tab bar**:

| Option | Behavior |
|---|---|
| **Always** | Tab bar always visible |
| **Only on hover** | Tab bar hidden in both modes until hover |
| **When windowed** | Tab bar only in windowed mode |

> [!info]
> On macOS, traffic lights are hidden when in windowed mode if tab bar is set to "Only on hover".

## Tab Close Button

Position the close button on either side of the tab.

### Configure

- **Settings** → **Appearance** → **Tabs** → **Tab close button position**:

| Option | Style |
|---|---|
| **Left** | macOS style |
| **Right** | Windows / Linux style |

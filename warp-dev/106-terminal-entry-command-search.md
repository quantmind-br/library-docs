Command Search provides unified search across terminal inputs, saved commands, and agent conversation history.

## Quick start

1. Press `CTRL-R` to open Command Search Panel
2. Type your search query
3. Press `ENTER` to input the selected command

## Search filters

Prepend search terms with:

- `ai_history:` — filter agent history
- `a:` or `A-TAB` — quick append

> [!info]
> Active filters display bold and italicized in the search panel.

## Additional features

- Drag right edge to expand menu horizontally
- Fuzzy search with relevance ranking

## Configuration

Toggle "Show Global Workflows" in **Settings** → **Features** → **Workflows** to include/exclude YAML and Warp Drive workflows from search.

# Changelog Audit

Audit changelog entries for all commits since the last release.

## Process

1. **Find last release tag:**
   ```bash
   git tag --sort=-version:refname | head -1
   ```

2. **List commits since that tag:**
   ```bash
   git log <tag>..HEAD --oneline
   ```

3. **Read each package's `[Unreleased]` section:**
   - `packages/ai/CHANGELOG.md`
   - `packages/tui/CHANGELOG.md`
   - `packages/coding-agent/CHANGELOG.md`

4. **For each commit, check:**
   - **Skip**: changelog updates, doc-only changes, release housekeeping
   - **Skip**: changes to generated model catalogs (e.g., `packages/ai/src/models.generated.ts`) unless accompanied by intentional product-facing change
   - Determine affected package(s) via `git show <hash> --stat`
   - Verify changelog entry exists in affected package(s)
   - **External contributions** (PRs) must use format: `Description ([#N](url) by [@user](url))`

5. **Cross-package duplication**: Changes in `ai`, `agent`, or `tui` affecting end users must be duplicated to `coding-agent` changelog.

6. **Add New Features section**: Insert `### New Features` at start of `## [Unreleased]` in `packages/coding-agent/CHANGELOG.md`. Confirm top features with user before writing.

7. **Report**: List commits with missing entries, entries needing cross-package duplication, and add any missing entries.

## Changelog Format

| Section | Purpose |
|---------|---------|
| `### Breaking Changes` | API changes requiring migration |
| `### Added` | New features |
| `### Changed` | Changes to existing functionality |
| `### Fixed` | Bug fixes |
| `### Removed` | Removed features |

**Attribution:**
- Internal: `Fixed foo ([#123](https://github.com/badlogic/pi-mono/issues/123))`
- External: `Added bar ([#456](https://github.com/badlogic/pi-mono/pull/456) by [@user](https://github.com/user))`

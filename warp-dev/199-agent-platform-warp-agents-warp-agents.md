Warp includes intelligent Oz agents to help you build, test, deploy, and debug while keeping you in control. Interactive agent conversations in Warp can look up commands, execute tasks, fix bugs, and adapt to your workflows with full context from Warp Drive and your team.

> [!info]
> Warp's AI features can be globally disabled in **Settings** > **Agents** > **Warp Agent** with the AI toggle. These features send input data to LLM providers through their API. Warp is **SOC 2 compliant** and has **Zero Data Retention** policies with all contracted LLM providers—no customer AI data is retained, stored, or used for training. See the [Warp privacy page](https://www.warp.dev/privacy) for data privacy details.
>
> Warp's client is open source under [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE) at [`warpdotdev/warp`](https://github.com/warpdotdev/warp). See [Contributing to Warp](https://docs.warp.dev/support-and-community/community/contributing) to read the code, file issues, or shape the roadmap.

## What you can do with agents

- [Interacting with Agents](https://docs.warp.dev/agent-platform/warp-agents/interacting-with-agents) — manage AI conversations, attach context, continue threads
- [Agent Context](https://docs.warp.dev/agent-platform/warp-agents/agent-context) — attach images, URLs, files, code blocks, and selections
- [Model Choice](https://docs.warp.dev/agent-platform/warp-agents/capabilities-overview/model-choice) — pick your preferred LLM or let Warp choose optimal
- [Full Terminal Use](https://docs.warp.dev/agent-platform/warp-agents/capabilities-overview/full-terminal-use) — let agents drive interactive terminal apps with live output
- [Interactive Code Review](https://docs.warp.dev/agent-platform/warp-agents/interactive-code-review) — review agent-generated diffs and leave inline comments
- [Task Lists](197-agent-platform-warp-agents-capabilities-overview-task-lists.md) — track complex workflows with real-time progress
- [Web Search](https://docs.warp.dev/agent-platform/warp-agents/capabilities-overview/web-search) — allow agents to search the web
- [Third-Party CLI Agents](https://docs.warp.dev/agent-platform/third-party-agents/overview) — run Claude Code, Codex, and other CLI agents with Warp's built-in toolbelt
- [Voice](https://docs.warp.dev/agent-platform/warp-agents/interacting-with-agents/voice) — talk to Warp's agent using voice commands

For foundational capabilities like planning, rules, MCP servers, and agent profiles, see [[198-agent-platform-warp-agents-capabilities-overview|Capabilities]].

Hyprland installs on NixOS via NixOS and Home Manager modules.

> [!warning]
> The **NixOS module** (`programs.hyprland.enable = true`) is required. Without it, your display manager may lack session files. The **Home Manager module** is optional — it configures Hyprland declaratively and adds it to `$PATH`, but system-level changes (e.g., desktop session files) are handled by the NixOS module.

## NixOS module[](#nixos-module)

```nix
{
  programs.hyprland.enable = true;
  # Optional: environment.sessionVariables.NIXOS_OZONE_WL = "1";
}
```

For all NixOS options, see [[018-nix-hyprland-on-nixos|Nix/Hyprland-on-NixOS]] or [module options](https://search.nixos.org/options?channel=unstable&size=50&sort=relevance&type=packages&query=hyprland).

## Overlays[](#overlays)

### default[](#default)

The `default` overlay includes only Hyprland, `xdg-desktop-portal-hyprland`, and internal dependencies (`udis86-hyprland`, `glaze-hyprland`). Import additional overlays manually for up-to-date hypr* packages.

### hyprland-packages[](#hyprland-packages)

For an overlay with all dependencies, import both `hyprland-packages` and `hyprland-extras`.

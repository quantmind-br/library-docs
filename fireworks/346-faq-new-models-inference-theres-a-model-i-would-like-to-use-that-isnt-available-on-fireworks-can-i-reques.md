# Model Availability Requests

Fireworks supports a wide array of custom models and actively takes feature requests for new, popular models.

## How to Request a Model

1. **Join our [Discord server](https://discord.gg/fireworks-ai)**
2. Let us know which models you'd like to see
3. Provide **use case details** to help prioritize

## Evaluation Criteria

New models are added based on:

- **Community requests**
- **Popular demand**
- **Technical feasibility**
- **Licensing requirements**

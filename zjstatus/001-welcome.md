Welcome to the zjstatus wiki 👋🏻


zjstatus is a statusbar plugin for [zellij](https://zellij.dev), a relative new approach on terminal multiplexers. Zellij offers a lot of customisations with the implementation of a plugin system with WASM. However, the default statusbars do not allow customisations. This is where zjstatus tries to fill the gap and provides highly flexible and configurable statusbars.

This wiki will have some sections that try to explain the installation and different aspects of the configuration. In case anything is written unclear or misleading, please feel free to open a discussion.

Happy tinkering!

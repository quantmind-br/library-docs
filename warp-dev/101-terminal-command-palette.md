Search and activate workflows, notebooks, actions, and files from a single interface.

## Access

Press `CMD-P`.

## Use

Start typing to search. Use filter buttons or prepend search terms:

| Prefix | Filters for |
|--------|-------------|
| `workflows:` or `w:` | [Workflows](https://docs.warp.dev/knowledge-and-collaboration/warp-drive/workflows) |
| `prompts:` or `p:` | [Prompts](https://docs.warp.dev/knowledge-and-collaboration/warp-drive/prompts) |
| `notebook:` or `n:` | [Notebooks](https://docs.warp.dev/knowledge-and-collaboration/warp-drive/notebooks) |
| `files:` | Local files |
| `actions:` | Warp-specific actions (settings, features, toggles) |

## GUI

- **[dolphin](https://github.com/KDE/dolphin)** — KDE file manager
- **[nautilus](https://apps.gnome.org/en/Nautilus/)** — GNOME file manager

  Extensions:
  - [nautilus-admin-gtk4](https://github.com/MacTavishAO/nautilus-admin-gtk4) — elevated privileges
  - [nautilus-image-converter](https://gitlab.gnome.org/coreyberla/nautilus-image-converter) — resize/rotate images
  - [nautilus-open-any-terminal](https://github.com/Stunkymonkey/nautilus-open-any-terminal) — open terminal in directory

- **[nemo](https://github.com/linuxmint/nemo)** — Cinnamon file manager

  Extensions:
  - [nemo-fileroller](https://github.com/linuxmint/nemo-extensions/tree/master/nemo-fileroller) — file archiver
  - [nemo-terminal](https://github.com/linuxmint/nemo-extensions/tree/master/nemo-terminal) — embedded terminal

- **[pcmanfm-qt](https://github.com/lxqt/pcmanfm-qt)** — LXQt file manager
- **[pcmanfm](https://github.com/lxde/pcmanfm)** — LXDE file manager
- **[thunar](https://gitlab.xfce.org/xfce/thunar)** — XFCE file manager

## TUI

- **[lf](https://github.com/gokcehan/lf)** — Go-written, ranger-inspired
- **[nnn](https://github.com/jarun/nnn)** — n^3, unorthodox terminal file manager
- **[ranger](https://github.com/ranger/ranger)** — Vim-inspired console file manager
- **[superfile](https://github.com/yorukot/superfile)** — modern fancy TUI
- **[yazi](https://yazi-rs.github.io/)** — async Rust, blazing fast

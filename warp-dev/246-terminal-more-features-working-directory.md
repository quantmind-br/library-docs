# Working Directory

Set a default directory for new terminal sessions to save time accessing preferred directories.

## Access

**Settings** > **Features** > **Session** > **Working directory for new sessions**.

| Option | Behavior |
|---|---|
| Home Directory | Opens `~/` (default) |
| Previous session's directory | Opens the current directory of your active session |
| Custom directory | Opens a path you specify |
| Advanced | Apply a different option per Window, Tab, or Pane |

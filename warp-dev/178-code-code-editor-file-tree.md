The native file tree auto-reflects your project structure as files change.

## Open the File Tree

- **Tools panel**: Click the Tools sidebar button, then File Tree tab.
- **Keyboard**: `CMD + \` to open left panel, assign shortcut in **Settings** > **Keyboard shortcuts**.

## Browse and Open Files

Click a file to open it directly in Warp's [[181-code-code-editor|native Code Editor]].

## File Actions (Right-Click)

| Action | Description |
|--------|-------------|
| Open in new pane | side-by-side view |
| Open in new tab | new tabbed viewer |
| Attach as context | insert into agent prompt |
| Copy path | absolute path |
| Copy relative path | relative to CWD |

## Folder Actions (Right-Click)

| Action | Description |
|--------|-------------|
| Create new file | add file from tree |
| Attach as context | insert into agent prompt |
| Copy path | absolute path |
| Copy relative path | relative to CWD |

First, vLLM must be [installed](https://docs.vllm.ai/en/latest/getting_started/installation/) for your chosen device in either a Python or Docker environment.

Then, vLLM supports the following usage patterns:

- [Inference and Serving](https://docs.vllm.ai/en/latest/serving/offline_inference/): Run a single instance of a model.
- [Deployment](https://docs.vllm.ai/en/latest/deployment/docker/): Scale up model instances for production.
- [Training](https://docs.vllm.ai/en/latest/training/rlhf/): Train or fine-tune a model.

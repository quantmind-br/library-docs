# Posts Tagged with Announcement

## DMS 1.4 - Saffron Bloom

DankMaterialShell (DMS) 1.4 "Saffron Bloom" introduces a brand new launcher, numerous plugin system improvements enabling GIFs, KDE Connect, Clight, and new possibilities for extending DMS.

## DMS 1.2 - Spicy Miso

DMS 1.2 "Spicy Miso" features numerous new features and major improvements to both the DMS core and plugin system.

The next DMS release introduces **Desktop Widgets** — applets that live on your desktop below windows and above the wallpaper. This pre-announcement highlights the plugin ecosystem and encourages community building of these new widget types.

## DMS 1.0 - The Dark Knight

DMS 1.0 is a Desktop Shell for Wayland Compositors built with [Quickshell](https://quickshell.org/) & Go. What started as a small hobby project has grown into a full desktop shell with thousands of users and dozens of contributors, with first-class support for [niri](https://github.com/niri-wm/niri), [Hyprland](https://hypr.land), [Sway](https://swaywm.org/), [MangoWC](https://mangowc.vercel.app/), and [LabWC](https://labwc.github.io/).

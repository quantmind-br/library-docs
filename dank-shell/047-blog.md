# Dank Linux Blog

Release announcements and project news for DankMaterialShell and related projects.

## DMS 1.4 "Saffron Bloom"

DMS 1.4 introduces a brand new launcher, numerous plugin system improvements (GIFs, KDE Connect, Clight), and new possibilities for extending DMS features.

## DMS 1.2 "Spicy Miso"

DMS 1.2 features numerous new features and major improvements to both the DMS core and plugin system.

## Desktop Widgets (Pre-Announcement)

The next DMS release adds **Desktop Widgets** — applets that live on the desktop below windows and above the wallpaper. This pre-announcement encourages community plugin development.

## DMS 1.0

DMS 1.0 marks the first stable release. What started as a hobby project grew into a full desktop shell and application suite with thousands of users and dozens of contributors.

Supported compositors: [niri](https://github.com/niri-wm/niri), [Hyprland](https://hypr.land), [Sway](https://swaywm.org), [MangoWC](https://mangowc.vercel.app/), [LabWC](https://labwc.github.io/) — plus general support for all compositors implementing select Wayland protocols.

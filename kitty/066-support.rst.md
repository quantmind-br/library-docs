# Support kitty development ❤️

kitty aims to move the stagnant terminal ecosystem forward with foundational features:

- [[049-graphics-protocol|Image support]] for rich terminal applications
- [[034-performance|Superlative performance]]
- [[057-protocol-extensions|Protocol enhancements]] enabling new terminal capabilities
- [[011-kittens-diff|Side-by-side diff]] kitten
- [[022-kittens-unicode-input|Unicode input]] kitten

Kovid has personally written [almost all kitty code](https://github.com/kovidgoyal/kitty/graphs/contributors).

## Ways to support

- **One-time payment**: PayPal donation
- **Recurring patronage**: GitHub Sponsors, Open Collective, or Patreon

Donations allow more dedicated development time on kitty.

> [!tip]
> kitty is free and open source. If it has made your workflow better, consider supporting its continued development.

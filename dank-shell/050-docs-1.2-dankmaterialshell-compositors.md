# Compositor Setup

DankMaterialShell works with any Wayland compositor. Optimized configurations are provided for niri, Hyprland, Sway, MangoWC, and labwc.

## niri

DMS integrates with niri's scrollable tiling via KDL config files. DMS auto-applies keybinds, gaps, window radius, and colors when you include:

```kdl
// ~/.config/niri/config.kdl
include "dms/colors.kdl"
include "dms/layout.kdl"
include "dms/alttab.kdl"
include "dms/binds.kdl"
```

> [!tip]
> Ensure all files exist before including: `mkdir -p ~/.config/niri/dms && touch ~/.config/niri/dms/{colors,layout,alttab,binds}.kdl`

### Layout
```kdl
layout {
    gaps 5
    background-color "transparent"
}
```

### Layer Rules
```kdl
layer-rule {
    match namespace="^quickshell$"
    place-within-backdrop true
}
// Blur wallpaper (if "Blur Layer" enabled)
layer-rule {
    match namespace="dms:blurwallpaper"
    place-within-backdrop true
}
```

See [[059-docs-1.2-dankmaterialshell-layers|Layer Rules]] for details.

### Startup
```bash
systemctl --user add-wants niri.service dms
```
Optional: `spawn-at-startup "bash" "-c" "wl-paste --watch cliphist store &"` for clipboard history.
Alternative (non-systemd): `spawn-at-startup "dms" "run"`

### Environment Variables
```kdl
environment {
  XDG_CURRENT_DESKTOP "niri"
  QT_QPA_PLATFORM "wayland"
  ELECTRON_OZONE_PLATFORM_HINT "auto"
  QT_QPA_PLATFORMTHEME "gtk3"
  QT_QPA_PLATFORMTHEME_QT6 "gtk3"
}
```

### DMS Keybindings
See [[075-docs-1.2-dankmaterialshell-keybinds-ipc|IPC commands]] for full list.

```kdl
binds {
    Mod+Space { spawn "dms" "ipc" "call" "spotlight" "toggle"; }
    Mod+V { spawn "dms" "ipc" "call" "clipboard" "toggle"; }
    Mod+M { spawn "dms" "ipc" "call" "processlist" "focusOrToggle"; }
    Mod+Comma { spawn "dms" "ipc" "call" "settings" "focusOrToggle"; }
    Mod+N { spawn "dms" "ipc" "call" "notifications" "toggle"; }
    Mod+Y { spawn "dms" "ipc" "call" "dankdash" "wallpaper"; }
    Mod+Alt+L { spawn "dms" "ipc" "call" "lock" "lock"; }
    XF86AudioRaiseVolume allow-when-locked=true { spawn "dms" "ipc" "call" "audio" "increment" "3"; }
    XF86AudioLowerVolume allow-when-locked=true { spawn "dms" "ipc" "call" "audio" "decrement" "3"; }
    XF86AudioMute allow-when-locked=true { spawn "dms" "ipc" "call" "audio" "mute"; }
    XF86MonBrightnessUp allow-when-locked=true { spawn "dms" "ipc" "call" "brightness" "increment" "5" ""; }
    XF86MonBrightnessDown allow-when-locked=true { spawn "dms" "ipc" "call" "brightness" "decrement" "5" ""; }
}
```

### Window Rules
```kdl
window-rule {
    match app-id=r#"^org\.gnome\."#
    draw-border-with-background false
    geometry-corner-radius 12
    clip-to-geometry true
}
window-rule {
    match app-id=r#"^org\.wezfurlong\.wezterm$"#
    match app-id="Alacritty"
    match app-id="zen"
    match app-id="com.mitchellh.ghostty"
    match app-id="kitty"
    draw-border-with-background false
}
window-rule {
    match is-active=false
    opacity 0.9
}
window-rule {
    geometry-corner-radius 12
    clip-to-geometry true
}
window-rule {
    match app-id=r#"org.quickshell$"#
    open-floating true
}
```

## Hyprland

Hyprland config at `~/.config/hypr/hyprland.conf`.

### Key Configuration Sections
```conf
source = ~/.config/hypr/dms/colors.conf
source = ~/.config/hypr/dms/layout.conf
source = ~/.config/hypr/dms/outputs.conf
```

> [!tip]
> Ensure files exist: `mkdir -p ~/.config/hypr/dms && touch ~/.config/hypr/dms/{colors,layout,outputs}.conf`

### Startup
```conf
exec-once = dbus-update-activation-environment --systemd WAYLAND_DISPLAY XDG_CURRENT_DESKTOP
exec-once = systemctl --user start hyprland-session.target
```
```bash
systemctl --user add-wants hyprland-session.target dms
```

See [[006-docs-1.2-dankmaterialshell-installation#hyprland|Installation guide]] for session target setup.
Optional: `exec-once = bash -c "wl-paste --watch cliphist store &"` for clipboard history.

### Miscellaneous
```conf
misc {
    disable_hyprland_logo = true
    disable_splash_rendering = true
}
```

### Environment Variables
```conf
env = QT_QPA_PLATFORM,wayland
env = ELECTRON_OZONE_PLATFORM_HINT,auto
env = QT_QPA_PLATFORMTHEME,gtk3
env = QT_QPA_PLATFORMTHEME_QT6,gtk3
```

### Layer Rules
```conf
layerrule = noanim, ^(dms)$
```

### General Layout
```conf
general {
    gaps_in = 5
    gaps_out = 5
    border_size = 0
    col.active_border = rgba(707070ff)
    col.inactive_border = rgba(d0d0d0ff)
    layout = dwindle
}
```

### Decoration
```conf
decoration {
    rounding = 12
    active_opacity = 1.0
    inactive_opacity = 0.9
    shadow {
        enabled = true
        range = 30
        render_power = 5
        offset = 0 5
        color = rgba(00000070)
    }
}
```

bind = $mod, N, exec, dms ipc call notifications toggle

## Other Compositors

DMS works with any Wayland compositor supporting:
- Layer shell protocol
- Session lock protocol
- ext-workspace-v1 protocol
- wlr-output-management-unstable-v1 protocol

Some compositor-specific features (e.g., workspace switching) may be unavailable.

### Basic Integration
1. Auto-start DMS
2. Configure keybindings using [[075-docs-1.2-dankmaterialshell-keybinds-ipc|IPC commands]]
3. Set environment variables in `~/.config/environment.d/90-dms.conf` (systemd) or compositor config

### Example for Sway
```conf
# ~/.config/sway/config
exec dms run
exec wl-paste --watch cliphist store
bindsym $mod+space exec dms ipc call spotlight toggle
bindsym $mod+v exec dms ipc call clipboard toggle
bindsym $mod+m exec dms ipc call processlist focusOrToggle
bindsym $mod+comma exec dms ipc call settings focusOrToggle
bindsym XF86AudioRaiseVolume exec dms ipc call audio increment 3
bindsym XF86AudioLowerVolume exec dms ipc call audio decrement 3
bindsym XF86AudioMute exec dms ipc call audio mute
bindsym XF86MonBrightnessUp exec dms ipc call brightness increment 5
bindsym XF86MonBrightnessDown exec dms ipc call brightness decrement 5
```

## Troubleshooting

### DMS doesn't start automatically
Check compositor logs for `exec-once` or equivalent. Manually start with `dms run` to see error messages.

### Keybindings don't work
Verify DMS is running (`pgrep -f "dms run"`) and keybinding syntax matches your compositor's format.

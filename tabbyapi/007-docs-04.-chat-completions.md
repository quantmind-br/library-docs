# 04. Chat Completions

TabbyAPI uses the HuggingFace "chat templates" standard for OAI-style chat completions (`/v1/chat/completions`). See the [autogenerated documentation](https://theroyallab.github.io/tabbyAPI/#operation/chat_completion_request_v1_chat_completions_post) for details.

## Custom Templates

By default, TabbyAPI pulls the chat template from the model's `chat_template` key in `tokenizer_config.json`. You can also create a custom Jinja2 file — see [HuggingFace's documentation](https://huggingface.co/docs/transformers/main/chat_templating). Consider PRing custom templates to the [templates repository](https://github.com/theroyallab/llm-prompt-templates).

### Stopping Strings

Add `{%- set stop_strings = ["string1"] -%}` at the top of the Jinja file to register stopping strings.

> [!warning]
> Use `{%- -%}` for all top-level metadata to avoid extra whitespace in the rendered prompt. This does not apply to comments `{# #}`.

### Using a Custom Template

1. Place the Jinja file in the templates folder.
2. Set `prompt_template` in `config.yml` to the template's filename (see [[006-docs-02.-server-options#model-options|model config]]).

## Template Variables

Pass custom key/value variables in the JSON body:

```json
"template_vars": {
    "test_var": "hello!"
}
```

> [!note]
> Use `chat_template_kwargs` instead of `template_vars` for compatibility with other standards.

Template example:

```jinja2
I'm going to say {{ test_var }}
```

Rendered output: `I'm going to say hello!`

## What are Blocks?

Blocks enable you to:

- Copy a command or its output
- Scroll directly to the start of a command's output
- Re-input commands
- Share both command and output (with formatting)
- Bookmark commands

> [!info]
> Interested in how Warp differentiates input and output, or implements blocks? See [How Warp Works](https://blog.warp.dev/how-warp-works/#implementing-blocks).

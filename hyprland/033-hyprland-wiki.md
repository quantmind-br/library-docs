# Hyprland Wiki

> [!info]
> This wiki is **versioned**. Default view shows latest Hyprland git commit. Select your tagged release via the version selector (check with `hyprctl version`).

## Wayland vs Xorg

A Wayland compositor is a fully autonomous Display Server. Unlike Xorg, you cannot mix'n'match Wayland compositors with window managers. Wayland compositors are not the same as Xorg window managers.

Xorg applications do not all work on Wayland. See [[082-useful-utilities|Useful Utilities]] for Wayland-native/recommended alternatives.

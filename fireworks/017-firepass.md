Fire Pass (Early Access) is a weekly pass providing **Kimi K2.5 Turbo** access for personal agentic coding harnesses — [Claude Code]([[034-ecosystem-integrations-claude-code]]), [OpenCode](https://opencode.ai), Cline, Kilo Code, OpenClaw, and [LangChain Deep Agents](https://docs.langchain.com/oss/python/deepagents/models) — with no per-token charges for that model.

> [!note]
> No invite code required. Anyone can purchase a pass.

Kimi K2.5 Turbo is a private preview of a faster Kimi K2.5 serverless API.

## What's Included

- **Kimi K2.5 Turbo** requests with zero per-token costs (256k context window, optimized for complex coding tasks)
- Standard Fireworks API access using your existing API key
- Full compatibility with OpenAI- and Anthropic-compatible agentic coding tools

## Pricing

| Item | Details |
|------|---------|
| **Cost** | $7 per week |
| **Payment** | Billed to credit card on file |
| **Auto-renew** | Optional — not guaranteed |

## General Configuration

If your tool supports custom API endpoints:

| Setting | Value |
|---------|-------|
| **Model ID** | `accounts/fireworks/routers/kimi-k2p5-turbo` |
| **API Key** | Your standard Fireworks API key ([generate here](https://app.fireworks.ai/api-keys)) |
| **Base URL (OpenAI-compatible)** | `https://api.fireworks.ai/inference/v1` |
| **Base URL (Anthropic-compatible)** | `https://api.fireworks.ai/inference` |

## Terms of Use

Fire Pass is for **personal agentic coding use only**.

- **Allowed**: Personal development, experimentation, and coding with agentic harnesses
- **Prohibited**: Production workloads, team/shared usage, and violations of the [Fireworks Terms of Service](https://fireworks.ai/terms-of-service)

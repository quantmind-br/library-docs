`dms screenshot` captures screenshots from Wayland displays with multiple capture modes, output formats, and clipboard integration. Press **Escape** to cancel region selection. Default format is `png`; use `--format` or `-f` to change it.

```bash
# Interactive selection, save file + clipboard
dms screenshot
# File only, no clipboard
dms screenshot --no-clipboard
# Clipboard only, no file
dms screenshot --no-file
```

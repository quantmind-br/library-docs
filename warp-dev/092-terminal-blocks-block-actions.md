Perform actions on terminal blocks: copy, share, bookmark, find, and filter.

## Access Block Actions

- **Mouse**: hover over a block, click the kebab (⋮) button on the right.
- **Keyboard**: right-click the block.

## Copy Input / Output

- **Command blocks**: right-click or use the context menu to copy the command, output, or both.
- **AI blocks**: right-click to copy the prompt, output, both, or the entire conversation.

## Share a Block

Create a web permalink that preserves formatting. See [[095-terminal-blocks-block-sharing]].

## Bookmark a Block

Quickly navigate to important blocks regardless of position in history.

- **Add bookmark**: select "Toggle bookmark" in the block context menu, or press `CMD-B` on a selected block.
- **Navigate**: click the indicator (position reflects block position in history; hover for a snapshot), or press `OPTION-UP` / `OPTION-DOWN`.

> [!warning]
> Bookmarks are session-only. To persist, share the block instead. See [[095-terminal-blocks-block-sharing]].

## Search Within a Block

Press "Find Within Block" or `CMD-F` with a block selected. See [[096-terminal-blocks-find]].

## Filter a Block

Show only matching output lines. See [[094-terminal-blocks-block-filtering]].

- Toggle with `OPT-SHIFT-F` (default) on the selected or latest block.
- Select "Toggle Block Filter" in the block context menu.

## GB\_bytes `module-attribute` [¶](#vllm.utils.mem_constants.GB_bytes "Permanent link")

```
GB_bytes = 1000000000
```

The number of bytes in one gigabyte (GB).

## GiB\_bytes `module-attribute` [¶](#vllm.utils.mem_constants.GiB_bytes "Permanent link")

```
GiB_bytes = 1 << 30
```

The number of bytes in one gibibyte (GiB).

## KB\_bytes `module-attribute` [¶](#vllm.utils.mem_constants.KB_bytes "Permanent link")

```
KB_bytes = 1000
```

The number of bytes in one kilobyte (KB).

## KiB\_bytes `module-attribute` [¶](#vllm.utils.mem_constants.KiB_bytes "Permanent link")

```
KiB_bytes = 1 << 10
```

The number of bytes in one kibibyte (KiB).

## MB\_bytes `module-attribute` [¶](#vllm.utils.mem_constants.MB_bytes "Permanent link")

```
MB_bytes = 1000000
```

The number of bytes in one megabyte (MB).

## MiB\_bytes `module-attribute` [¶](#vllm.utils.mem_constants.MiB_bytes "Permanent link")

```
MiB_bytes = 1 << 20
```

The number of bytes in one mebibyte (MiB).

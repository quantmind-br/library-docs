# Codex SDK

Programmatic control of Codex. Use when you need to:
- Control Codex in CI/CD pipelines
- Create your own agent for complex engineering tasks
- Build Codex into internal tools and workflows
- Integrate Codex within your own application

## TypeScript

Server-side library; requires Node.js 18+.

```bash
npm install @openai/codex-sdk
```

```ts
const codex = new Codex();
const thread = codex.startThread();
const result = await thread.run("Make a plan to diagnose and fix the CI failures");
console.log(result);
```

Call `run()` again to continue the same thread, or resume by thread ID:
```ts
const thread2 = codex.resumeThread("<thread-id>");
const result2 = await thread2.run("Pick up where you left off");
```

[TypeScript repo](https://github.com/openai/codex/tree/main/sdk/typescript)

## Python

Experimental. Controls the local Codex app-server over JSON-RPC. Requires Python 3.10+ and a local checkout of the open-source Codex repo.

```bash
cd sdk/python
python -m pip install -e .
```

```python
from codex_app_server import Codex

with Codex() as codex:
    thread = codex.thread_start(model="gpt-5.4")
    result = thread.run("Make a plan to diagnose and fix the CI failures")
    print(result.final_response)
```

For async applications:
```python
import asyncio
from codex_app_server import AsyncCodex

async def main() -> None:
    async with AsyncCodex() as codex:
        thread = await codex.thread_start(model="gpt-5.4")
        result = await thread.run("Implement the plan")
        print(result.final_response)

asyncio.run(main())
```

# NixOS Installation (Flake)

Install DankMaterialShell on NixOS via system-wide NixOS module or per-user home-manager using flakes.

> [!info]
> DankMaterialShell is now available in nixpkgs unstable! If you're on NixOS unstable (26.05), see [[055-docs-dankmaterialshell-nixos|NixOS Installation]] for the native nixpkgs method.

## Installation Methods

- **NixOS Module**: System-wide installation, ideal for multi-user systems
- **Home-Manager Module**: Per-user installation, ideal for single-user setups or user-specific configurations

## Installation

### 1. Add Flake Inputs

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    dms = {
      url = "github:AvengeMedia/DankMaterialShell/stable";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
}
```

> [!tip]
> For the unstable (-git) version, remove `/stable` from the URL. The unstable version may contain breaking changes.

### 2. Import the NixOS or home-manager Module

**NixOS module:**

```nix
imports = [
  inputs.dms.nixosModules.dank-material-shell
];
```

**Home-manager module:**

```nix
imports = [
  inputs.dms.homeModules.dank-material-shell
];
```

### 3. Enable DankMaterialShell

```nix
programs.dank-material-shell.enable = true;
```

Rebuild and DMS is installed with sensible defaults.

> [!warning]
> `dgop` is not available in nixpkgs stable (25.11). If using NixOS stable, import dgop from the flake and manually set the package:

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-25.11";
    dms = {
      url = "github:AvengeMedia/DankMaterialShell/stable";
      inputs.nixpkgs.follows = "nixpkgs";
    };
    dgop = {
      url = "github:AvengeMedia/dgop";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
}
```

Then:

```nix
programs.dank-material-shell = {
  enable = true;
  enableSystemMonitoring = true;
  dgop.package = inputs.dgop.packages.${pkgs.system}.default;
};
```

## niri Integration

The home-manager module provides additional integration options for niri, including automatic keybindings and startup configuration.

> [!warning]
> The `niri-stable` package from niri-flake is version `25.08`, while DankMaterialShell needs `25.11` (available in nixpkgs).

### Prerequisites

If using [niri-flake](https://github.com/sodiboo/niri-flake):

```nix
niri = {
  url = "github:sodiboo/niri-flake";
  inputs.nixpkgs.follows = "nixpkgs";
};
```

```nix
imports = [
  inputs.niri.homeModules.niri
];
```

> [!tip]
> If using niri-flake's NixOS module (`inputs.niri.nixosModules.niri`), the home-manager module is already included.

### Enable niri Module

```nix
imports = [
  inputs.dms.homeModules.dank-material-shell
  inputs.dms.homeModules.niri
];
```

```nix
programs.dank-material-shell = {
  enable = true;
  niri = {
    enableKeybinds = true;  # Sets static preset keybinds
    enableSpawn = true;      # Auto-start DMS with niri
  };
};
```

> [!note]
> Do not use both `systemd.enable` and `niri.enableSpawn` simultaneously — this spawns two DMS instances.

### Config Includes

The niri home-manager module has a "hack" for config includes under `programs.dank-material-shell.niri.includes`.

> [!note]
> It is not recommended to use both `niri.includes` (enabled by default) and `niri.enableKeybinds` simultaneously — conflicts may occur. Also, this will overwrite `~/.config/niri/config.kdl`, so niri-flake generated files go in `~/.config/niri/hm.kdl` instead.

> [!tip]
> Files referenced by `filesToInclude` must exist or niri will error on startup. Use `dms setup` to deploy defaults — or generate individual files like `dms setup binds`, `dms setup colors`, etc.

**Defaults:**

```nix
programs.dank-material-shell = {
  enable = true;
  niri.includes = {
    enable = true;         # Enable config includes hack. Enabled by default.
    override = true;       # If disabled, DMS settings won't be prioritized over niri-flake settings
    originalFileName = "hm";  # New name for the config file generated by niri-flake.
    filesToInclude = [
      "alttab"   # niri will error if any of these files are missing
      "binds"
      "colors"
      "layout"
      "outputs"
      "wpblur"
    ];
  };
}
```

### Polkit Agent

If using DankMaterialShell's built-in polkit agent with niri-flake's NixOS module, disable niri-flake's default polkit agent:

```nix
systemd.user.services.niri-flake-polkit.enable = false;
```

## Configuration Options

> [!info]
> The options below work for **both** NixOS and home-manager modules. The NixOS module installs packages system-wide and places quickshell configs in `/etc/xdg/quickshell/dms`. The home-manager module additionally supports plugins, default settings, and default session configuration.

### Feature Toggles

```nix
programs.dank-material-shell = {
  enable = true;
  systemd = {
    enable = true;           # Systemd service for auto-start
    restartIfChanged = true; # Auto-restart dms.service when dank-material-shell changes
  };
  # Core features
  enableSystemMonitoring = true;  # System monitoring widgets (dgop)
  enableVPN = true;               # VPN management widget
  enableDynamicTheming = true;     # Wallpaper-based theming (matugen)
  enableAudioWavelength = true;    # Audio visualizer (cava)
  enableCalendarEvents = true;     # Calendar integration (khal)
  enableClipboardPaste = true;     # Pasting items from the clipboard (wtype)
};
```

### Custom Quickshell Package

> [!info]
> The DankMaterialShell flake already uses Quickshell built from source by default, as many features rely on unreleased Quickshell features. No additional configuration is needed.

To override:

```nix
programs.dank-material-shell = {
  enable = true;
  quickshell.package = pkgs.quickshell; # or your custom package
};
```

### Settings (home-manager only)

```nix
programs.dank-material-shell = {
  enable = true;
  settings = {
    theme = "dark";
    dynamicTheming = true;
  };
  session = {
    isLightMode = false;
  };
  clipboardSettings = {
    maxHistory = 25;
    maxEntrySize = 5242880;
    autoClearDays = 1;
    clearAtStartup = true;
    disabled = false;
    disableHistory = false;
    disablePersist = true;
  };
};
```

> [!tip]
> If you change settings in the GUI while managing with home-manager, you'll get a popup saying settings are read-only with an option to copy. Use json2nix on the copied settings to update your home-manager configuration.

Complete up-to-date lists of available settings:
- [SettingsSpec.js](https://raw.githubusercontent.com/AvengeMedia/DankMaterialShell/refs/heads/master/quickshell/Common/settings/SettingsSpec.js)
- [SessionSpec.js](https://github.com/AvengeMedia/DankMaterialShell/raw/refs/heads/master/quickshell/Common/settings/SessionSpec.js)

### Plugins

Two methods:

#### Method 1: Plugin Registry (Recommended)

The [dms-plugin-registry](https://github.com/AvengeMedia/dms-plugin-registry) flake provides all community plugins with daily updates.

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    dms = {
      url = "github:AvengeMedia/DankMaterialShell/stable";
      inputs.nixpkgs.follows = "nixpkgs";
    };
    dms-plugin-registry = {
      url = "github:AvengeMedia/dms-plugin-registry";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
}
```

```nix
{
  imports = [
    inputs.dms.homeModules.dank-material-shell
    inputs.dms-plugin-registry.modules.default
  ];
  programs.dank-material-shell = {
    enable = true;
    plugins = {
      dankBatteryAlerts.enable = true;
      dockerManager.enable = true;
      mediaPlayer = {
        enable = true;
        settings = {
          preferredSource = "spotify";
        };
      };
    };
  };
}
```

Plugin IDs are the last part of the install URL (e.g., `dms://plugin/install/dankBatteryAlerts` → `dankBatteryAlerts`).

#### Method 2: Manual Installation from Source

```nix
programs.dank-material-shell = {
  enable = true;
  plugins = {
    DockerManager = {
      src = pkgs.fetchFromGitHub {
        owner = "LuckShiba";
        repo = "DmsDockerManager";
        rev = "v1.2.0";
        sha256 = "sha256-VoJCaygWnKpv0s0pqTOmzZnPM922qPDMHk4EPcgVnaU=";
      };
      settings = {
        someOption = "value";
      };
    };
    AnotherPlugin = {
      enable = true;
      src = pkgs.another-plugin;
    };
  };
};
```

#### Plugin Settings Management (home-manager only)

| Scenario | Behavior |
|----------|----------|
| No plugin settings defined, `managePluginSettings = true` | Minimal `plugin_settings.json` created |
| Plugin settings defined | `managePluginSettings` defaults to `true`, settings go in `plugin_settings.json` |
| Plugin settings defined, `managePluginSettings = false` | Warning shown, `plugin_settings.json` not created |

## Rebuilding

```bash
# Home-manager standalone
home-manager switch
# NixOS with home-manager as a module
sudo nixos-rebuild switch
```

## Troubleshooting

**DMS doesn't start automatically:** Ensure `systemd.enable = true` or `niri.enableSpawn = true` is set.

**Missing dependencies:** Each feature has its own dependency set. Verify the corresponding `enable` option is `true` (e.g., `enableSystemMonitoring = true` installs `dgop`).

**Custom keybindings conflict with niri defaults:** Disable `niri.enableKeybinds = true` and manually configure using examples in [[084-docs-dankmaterialshell-keybinds-ipc|Keybinds & IPC]].

# Code Diffs

Review, navigate, refine, and apply code diffs generated by the Warp AI agent within the terminal environment.

> [!warning]
> If `Apply Code Diffs` permission is set to `Always allow` in [Agent Profiles & Permissions](https://docs.warp.dev/agent-platform/warp-agents/capabilities-overview/agent-profiles-permissions), diffs are applied automatically. If set to `Agent decides` or `Always ask`, you'll be prompted to review before applying.

> [!info]
> Code diffs are never stored on Warp servers. The coding agent only works on local repositories. For remote or docker repositories, it falls back to terminal commands (`sed`, `grep`).

You can also choose whether Warp automatically opens the [Code Review](https://docs.warp.dev/code/code-review) panel the first time you accept a diff.

## Reviewing Code Diffs

During an Agent Conversation, Warp generates code diffs that open in a built-in diff editor. Review proposed changes line by line, refine with natural language, or make manual edits before applying.

## Navigating and Applying Diffs

When an Agent generates a code diff, Warp opens it in a built-in text editor with a visual diff view. Changes are grouped into clear hunks.

- Use `UP`/`DOWN` arrow keys (or mouse clicks) to move between hunks
- Use `LEFT`/`RIGHT` arrow keys to switch between files (multi-file changes)
- Press `ENTER` or click **Accept Changes** to apply modifications

> [!warning]
> Modifications will not be applied unless you explicitly accept them.

## Refining or Editing the Diffs

| Action | Key/Button | Description |
|--------|------------|-------------|
| Refine | `R` or **Refine** button | Provide follow-up instructions in natural language; agent regenerates the diff |
| Edit manually | `E` or **Edit** button | Switch into an editable view |
| Cancel | `CTRL-C` | Cancel a pending operation |
| Exit | `ESC` | Exit the editor at any time |

## Accepting Diffs and Continuing in Agent Mode

When the Agent generates a code diff outside of an active conversation (e.g., from a suggested code banner), you can accept the diff and seamlessly continue in Agent Mode. After accepting, Warp opens (or returns to) the Agent conversation with the applied changes as context.

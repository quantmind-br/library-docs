Triggers execute cloud agents automatically without manual intervention. Set up agents to run on schedules, in response to webhooks, or through other automation patterns.

→ [Get started with scheduled agents](https://docs.warp.dev/agent-platform/cloud-agents/triggers/scheduled-agents-quickstart)

## Available trigger types

| Trigger | Description |
|---------|-------------|
| [**Scheduled Agents**](https://docs.warp.dev/agent-platform/cloud-agents/triggers/scheduled-agents) | Run agents on recurring schedules using cron expressions |
| [**CLI**](https://docs.warp.dev/reference/cli) | Trigger cloud agents directly from terminal |
| [**API & SDK**](https://docs.warp.dev/reference/api-and-sdk) | Programmatically trigger agents via API or SDK |
| [**Integrations**](https://docs.warp.dev/agent-platform/cloud-agents/integrations) | Trigger from Slack, Linear, GitHub Actions, and other external services |

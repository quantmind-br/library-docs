# 09. Community Projects

Third-party applications that integrate with the TabbyAPI backend.

> [!tip]
> Want to showcase a project? Contact a dev!

- [TabbyAPI Gradio Loader](https://github.com/theroyallab/tabbyAPI-gradio-loader) by Doctor Shotgun — Gradio WebUI for loading/unloading models and LoRAs via TabbyAPI.
- [ST TabbyAPI Loader](https://github.com/theroyallab/ST-tabbyapi-loader) by kingbri — SillyTavern extension for loading/unloading models via TabbyAPI.
- [SillyTavern Launcher](https://github.com/SillyTavern/SillyTavern-Launcher) by deffcolony — CLI manager for AI tools with packaged TabbyAPI setup.
- [SillyTavern](https://github.com/SillyTavern/SillyTavern) by Cohee and RossAscends — AI frontend for power users; fully supports TabbyAPI's generation options.
- [Agnaistic](https://agnai.chat/) by Sceik — Multi-user AI role-play chat frontend; fully supports TabbyAPI's generation options.
- [DS-LLM-WebUI](https://github.com/DocShotgun/ds-llm-webui) by Doctor Shotgun — Tool-use assistant for local LLMs, designed around TabbyAPI.
- [PolyMind](https://github.com/itsme2417/PolyMind) by Itsme2417 — Multimodal function-calling LLM WebUI designed for TabbyAPI.

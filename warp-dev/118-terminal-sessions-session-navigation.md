## Overview

Session Navigation lets you jump to any session in Warp, ordered by recency.

## Accessing Session Navigation

1. Open via [[104-terminal-command-palette|Command Palette]] → click **session >_** or type "sessions:".
2. Navigate with mouse or `UP`/`DOWN` arrow keys + `ENTER`.
3. Search by prompt, running command, last command, or status (e.g., "Running…", "Completed 10 minutes ago").

> [!info]
> Sessions ordered by recency; most recently focused first. Palette doesn't support PS1; shows only Warp's native prompt.

## CTRL-TAB Behavior

`CTRL-TAB` defaults to switching [[110-terminal-more-features-blocks-output|Tabs]]. Configure to cycle recent sessions (including [[110-terminal-more-features-blocks-output|Split Panes]]) at **Settings** → **Features** → **Keys** → **Ctrl-Tab behavior**.

# Input Position

Choose from three input positions, each with different flow behavior for input/output blocks.

### Access

**Settings** → **Appearance** → **Input**. Changes apply immediately to all open panes.

### Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `CMD-K` | Clear all input/output blocks for a clean view |
| `CTRL-L` | Scroll past all blocks for a clean view |
| `SHIFT-CMD-UP` / `SHIFT-CMD-DOWN` | Scroll to top/bottom of selected block (long blocks) |

`dms cl` is a Wayland clipboard manager with history, search, and configuration. It uses the `ext_data_control_v1` protocol.

| Command | Description |
|---------|-------------|
| `dms cl copy` | Copies data to the Wayland clipboard. Forks a background process by default. |
| `dms cl paste` | Reads current clipboard selection and writes to stdout. |
| `dms cl watch` | Watches for clipboard changes; prints changes to stdout without arguments. |
| `dms cl list` | Lists history entries with ID, type, timestamp, and preview. Requires DMS server. |
| `dms cl get <id>` | Retrieves full entry data by ID. Outputs raw data by default. |
| `dms cl delete <id>` | Deletes a history entry by ID. Requires DMS server. |
| `dms cl clear` | Clears all clipboard history. Requires DMS server. |
| `dms cl search <query>` | Searches history with text matching and filters. Requires DMS server. |
| `dms cl config` | Gets current clipboard manager configuration as JSON. |
| `dms cl set <key=value...>` | Updates configuration options. |

History table format:

```text
ID       Type        Timestamp            Preview
─────────────────────────────────────────────────────────────
1        text/plain  2024-01-15 10:30:00  Hello, world!
2        image/png   2024-01-15 10:31:00  [image 1920x1080]
3        text/plain  2024-01-15 10:32:00  Some longer text that gets trunca...
```

Settings are stored at `$XDG_CONFIG_HOME/DankMaterialShell/clsettings.json` (defaults to `~/.config/DankMaterialShell/clsettings.json`):

```json
{
"disabled":false,
"disableHistory":false,
"maxHistory":100,
"maxEntrySize":10485760,
"autoClearDays":0,
"clearAtStartup":false
}
```

For programmatic access, the clipboard manager exposes JSON-RPC methods over the DMS IPC socket.

Share blocks as permalinks or HTML embeds via the context menu.

## Share a Block

1. Click the context menu on a finished block and select **Share...**, or select the block and press `CMD-SHIFT-S`.
2. Title the block and choose which parts to share (command, output, prompt, etc.).
3. Click "Create link" or "Get embed".
4. The link or `iframe` snippet is copied to your clipboard.

> [!warning]
> This sends command data to Warp's server and is opt-in. See the [privacy page](https://www.warp.dev/privacy).

## Permalink

Share a permalink for team collaboration. Anyone with the link can view the block.

## Embedded Blocks

Embed blocks on web pages so readers interact with them as they would in Warp. Clicking "Get embed" copies an `iframe` to your clipboard.

## Manage Shared Blocks

Unshare a block via **Settings** > **Shared blocks**. Shared blocks are accessible to anyone with the link.

## Link Previews

Shared permalinks display a code preview on Slack, Twitter, Facebook, Telegram, Notion, and any platform supporting Open Graph or Twitter meta tags.

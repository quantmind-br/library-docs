Warp is an Agentic Development Environment (ADE) — a terminal that blends traditional CLI workflows with AI-driven automation via an integrated agent.

## Prompt-Based Coding

When you type natural language (e.g., *"describe my open git changes"*), Warp's agent automatically:

- Gathers relevant context (repo, files, command output)
- Runs the required commands
- Returns a structured answer or takes the requested action

You can also use Warp like a traditional terminal — type shell commands and they execute exactly as expected.

## Blending Terminal and Agentic Workflows

No context-switching between apps — it is all one environment:

- Type shell commands like a normal terminal
- Prompt the agent for debugging, code review, or environment setup
- Mix both freely in a single session

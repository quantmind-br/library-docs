# GitHub authentication email

Fireworks uses the **primary email address** from your GitHub account as your account identifier.

## Changing your primary email

1. Go to [GitHub email settings](https://github.com/settings/emails)
2. Select your desired email in the "Primary email address" section

## Switching between Fireworks accounts

Update your GitHub primary email before logging in to switch which Fireworks account GitHub authenticates into. This lets you:

- Log into different Fireworks accounts using the same GitHub account
- Switch between personal and work accounts
- Maintain separate billing and usage tracking per email address

> [!info]
> The authentication uses whichever email is set as primary at login time.

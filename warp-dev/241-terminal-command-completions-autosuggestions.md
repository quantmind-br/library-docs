# Autosuggestions

> [!tip]
> Map autosuggestion acceptance to `Tab` and configure automatic completions menu opening.

### Configure

- **Settings** → **Features** → **Terminal Input** → **Tab key behavior**: select Tab to accept autosuggestions.
- **Settings** → **Features** → **Terminal Input** → enable **Open completions menu as you type**.

> [!note]
> Setting Tab to accept autosuggestions changes the completions menu shortcut to `CTRL-SPACE`.

# Overview

Sampler overrides let you set defaults, force specific values, or append to client-provided sampler parameters before generation.

## Setting Up

All supported samplers are in `sampler_overrides/sample_preset.yml`.

> [!note]
> Overrides can be switched at runtime via the `/v1/sampling/override` endpoint. See the [API docs](https://theroyallab.github.io/tabbyAPI/#operation/list_sampler_overrides_v1_sampling_override_list_get).

1. Create a new YAML in `sampler_overrides/` or duplicate `sample_preset.yml`.
2. Adjust samplers using the examples below.
3. Save and rename the file.
4. In `config.yml`, set `sampling.sampler_override` to the preset name.

## Examples

### Set a default fallback

Client doesn't send `top_p`:

```yml
top_p:
    override: 0.7
    force: False
```

Changes the default fallback from 1.0 to 0.7.

### Force a value

Client sends an unwanted value (e.g., `top-k: 30`):

```yml
top_k:
    override: 0
    force: True
```

Forces `top_k` to 0 regardless of client input.

### Append to a list

Client sends a list; you want to add more:

```yml
stop:
    override: ["a"]
    force: False
    additive: True
```

Appends `"a"` to whatever stop strings the client sends.

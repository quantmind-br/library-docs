Warp Enterprise brings Warp's **Agentic Development Environment** to your entire engineering organization with governance features IT and security teams require.

**Two core products:**
- **Warp Terminal** — modern terminal for agentic development where developers run commands, collaborate with agents, and orchestrate autonomous work from the command line
- **Oz** — programmable agent for running and coordinating agents at scale with orchestration, tracking, and control plane

---

## Who Warp Enterprise is for

| Audience | Use case |
|----------|----------|
| **IT admins and platform teams** | Deploy and manage Warp across the organization with SSO, centralized administration, and usage visibility |
| **Engineering managers** | Give teams powerful agent development tools while enforcing coding standards through shared team resources |
| **Professional developers** | Accelerate work across the SDLC with state-of-the-art agents, team knowledge sharing, and collaborative workflows |

## Key capabilities

### Enterprise administration

- **Single Sign-On (SSO)** — authenticate via Okta, Microsoft Entra ID, Google Workspace, and more
- **Centralized Admin Panel** — manage team settings, user permissions, and feature controls
- **User roles and permissions** — Team Owner, Team Admin, and Member roles
- **Usage visibility** — monitor team adoption and agent usage

### Security and compliance

- **SOC 2 Type II certified**
- **Zero Data Retention (ZDR)** — no customer data retained, stored, or used for training by contracted LLM providers
- **Bring Your Own LLM (BYOLLM)** — route inference through your own cloud infrastructure (AWS Bedrock)
- **Flexible deployment** — Warp-hosted or hybrid deployment models
- **Telemetry controls** — configure what data is collected at the team level

### Team collaboration

- **Warp Drive team workspace** — share Workflows, Notebooks, Prompts, Plans, Rules, and Environment Variables
- **Codebase Context** — team-level code indexing for accurate, context-aware agent responses
- **MCP integrations** — connect to Linear, Sentry, Figma, GitHub, and more
- **Session sharing** — collaborate on terminal sessions and Oz conversations with shareable links

### Oz agent capabilities

- **State-of-the-art agents** — multi-model agents with full terminal access, code editing, and autonomous task execution
- **Oz cloud agents** — run agents in the cloud for unlimited parallelization, background automation, and long-running workflows
- **Integrated control plane** — launch, orchestrate, and manage local, cloud, and autonomous agents from a unified interface
- **Agent Profiles** — customize behavior, models, autonomy levels, and permissions
- **Rules and guardrails** — enforce coding standards, tech stack preferences, and security practices
- **Multi-agent support** — Oz, Claude Code, Codex, Copilot, and all major models

## Getting started

**For IT admins:** Start with the [Admin Panel](https://docs.warp.dev/enterprise/team-management/admin-panel) to manage team settings and enforce security controls. See [Roles and permissions](https://docs.warp.dev/enterprise/team-management/roles-and-permissions).

**For developers:** Jump to [Getting started for developers](https://docs.warp.dev/enterprise/getting-started/getting-started-developers) to download Warp and start using Codebase Context and Warp Drive. Or try the [Enterprise quickstart](https://docs.warp.dev/enterprise/getting-started/quickstart) for a 10-minute walkthrough.

**For security teams:** Review the [Security page](https://www.warp.dev/legal/security) and [Privacy documentation](https://docs.warp.dev/support-and-community/privacy-and-security/privacy).

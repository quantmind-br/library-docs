# Does the API support batching and load balancing?

Yes. Current capabilities:

- **Load balancing**: Supported out of the box
- **Continuous batching**: Supported
- **Batch inference**: Supported via [[068-guides-batch-inference|Batch API]]
- **Streaming**: Supported

For asynchronous batch processing of large request volumes, see [[068-guides-batch-inference|Batch API documentation]].

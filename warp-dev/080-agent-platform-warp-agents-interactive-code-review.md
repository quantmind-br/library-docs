# Interactive Code Review

Review, annotate, and refine code generated by any supported agent (Warp's native Agent or third-party CLI agents) using a pull-request style workflow inside Warp.

> [!info]
> Both the [Code Review](https://docs.warp.dev/warp/code/code-review) panel and Interactive Code Review require working in a Git-indexed directory.

## Supported Agents

- **Warp's native Agent** — the built-in agent in Agent Mode
- **Third-party CLI agents** — Claude Code, OpenAI Codex, OpenCode, Amp, Auggie, Copilot CLI, Cursor CLI, Gemini CLI, Droid, and Pi

For the full feature matrix and setup details, see [Third-Party CLI Agents](https://docs.warp.dev/agent-platform/third-party-agents/overview).

## How It Works

When an agent modifies files, Warp automatically gathers edits into a diff. Opening the Code Review panel shows every change the agent made. Leave inline comments on specific lines, batch feedback, and submit all changes back to the agent in one pass.

## Leave Inline Comments

Select any changed line or block and add a comment describing what you want adjusted. Warp anchors each comment to the relevant file and line so the agent understands exactly what to fix.

## Batch Comments and Submit Once

Add as many comments as needed before submitting. The agent receives your entire batch, applies changes in one iteration, and returns an updated diff.

## Workflow Demo

1. Open the Code Review panel after an agent produces changes
2. Browse the diffs for each edited file
3. Add multiple inline comments
4. Review all comments in the list view
5. Send comments to the agent for resolution
6. Inspect updated diffs once the agent applies changes

Repeat until the code matches your expectations.

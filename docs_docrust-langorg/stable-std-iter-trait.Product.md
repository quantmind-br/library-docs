## Trait Product

1.12.0 · [Source](https://doc.rust-lang.org/stable/src/core/iter/traits/accum.rs.html#38)

```rust
pub trait Product<A = Self>: Sized {
    // Required method
    fn product<I>(iter: I) -> Self
       where I: Iterator<Item = A>;
}
```

Expand description

Trait to represent types that can be created by multiplying elements of an iterator.

This trait is used to implement [`Iterator::product()`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#method.product "method std::iter::Iterator::product"). Types which implement this trait can be generated by using the [`product()`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#method.product "method std::iter::Iterator::product") method on an iterator. Like [`FromIterator`](https://doc.rust-lang.org/stable/std/iter/trait.FromIterator.html "trait std::iter::FromIterator"), this trait should rarely be called directly.

1.12.0 · [Source](https://doc.rust-lang.org/stable/src/core/iter/traits/accum.rs.html#42)

Takes an iterator and generates `Self` from the elements by multiplying the items.

This trait is **not** [dyn compatible](https://doc.rust-lang.org/1.95.0/reference/items/traits.html#dyn-compatibility).

*In older versions of Rust, dyn compatibility was called "object safety", so this trait is not object safe.*

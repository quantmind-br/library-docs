## Email

For account, billing, integration, or sensitive questions:

[**unclecode@crawl4ai.com**](mailto:unclecode@crawl4ai.com)

## GitHub

For bugs, feature requests, and library issues:

[**github.com/unclecode/crawl4ai/issues**](https://github.com/unclecode/crawl4ai/issues)

Please search existing issues first, and include a minimal reproducible example when filing a bug.

- **Discord** — chat with other users and the team: [discord.gg/crawl4ai](https://discord.gg/crawl4ai)
- **Twitter / X** — release news and tips: [@unclecode](https://twitter.com/unclecode)

## Status

Live status of the hosted service:

- Dashboard: [crawl4ai.com/dashboard](https://crawl4ai.com/dashboard)
- Incidents and maintenance windows are posted in the in-app notification bell

## Security

Found a vulnerability? Please report it privately so we can fix it before disclosure:

[**unclecode@crawl4ai.com**](mailto:unclecode@crawl4ai.com)

Include reproduction steps and the affected component. We will acknowledge within 48 hours and keep you informed through resolution.

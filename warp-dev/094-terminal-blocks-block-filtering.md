Filter block output lines to focus on a subset without deleting anything.

## Filter a Block

1. Click the filter icon in the top-right corner of a block.
2. Type in the left input field — only matching lines are shown.
3. (Optional) Enable regex, case-sensitive, or invert toggles.
4. (Optional) Add context lines by entering a number in the right input field.

Toggle filtering via:
- `OPT-SHIFT-F` (default) on the selected or latest block.
- "Toggle Block Filter" in the block context menu.

> [!note]
> Toggling a filter on a block with no filter opens the editor. Toggling off then on again reapplies the same filter.

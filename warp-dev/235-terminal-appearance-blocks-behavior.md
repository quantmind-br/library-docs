# Blocks Behavior

Customize block spacing with Compact Mode and toggle horizontal dividers between command blocks.

## Compact Mode

Condenses spacing between [[224-terminal-blocks|Blocks]] to show more content. Disabled by default.

### Enable Compact Mode

- **Settings** → **Appearance** → **Blocks** → **Compact Mode**
- [[101-terminal-command-palette|Command Palette]] → search "Compact mode"

![Compact Mode Demo](https://docs.warp.dev/~gitbook/image?url=https%3A%2F%2F4009768362-files.gitbook.io%2F~%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FPsjNxoJ0NFCXW6rRdHH3%252Fuploads%252Fgit-blob-9aa9ae8b6c35b85a591da228861e0ab6ccf7a154%252Fcompact_mode.gif%3Falt%3Dmedia&width=768&dpr=3&quality=100&sign=b590318e&sv=2)

> [!info]
> Warp persists compact settings across sessions.

## Block Dividers

Horizontal lines separating individual command input and output. Enabled by default.

### Toggle Block Dividers

- **Settings** → **Appearance** → **Blocks** → **Show block dividers**
- [[101-terminal-command-palette|Command Palette]] → search "Block Dividers"

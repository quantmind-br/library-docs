# Start

The config is at `$XDG_CONFIG_HOME/hypr/hyprland.conf` (typically `~/.config/hypr/hyprland.conf`). Use `--config` (or `-c`) to specify a different file.

Hyprland auto-generates an example config if none exists. Find one [here](https://github.com/hyprwm/Hyprland/blob/main/example/hyprland.conf). Remove the line containing `autogenerated=1` to eliminate the yellow warning.

The config reloads on save, or manually via `hyprctl reload`.

> [!warning]
> The default config is incomplete. Refer to this wiki and linked pages for full configuration.

> [!important]
> Read the [[067-configuring-variables|Variables]] page — it covers all toggleable/numerical options.

## Section Syntax

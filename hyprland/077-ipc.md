Hyprland exposes 2 UNIX Sockets for controlling/getting info about Hyprland.

## Hyprland Instance Signature (HIS)

```sh
echo $HYPRLAND_INSTANCE_SIGNATURE
```

## Socket 1: `.socket.sock`

Path: `$XDG_RUNTIME_DIR/hypr/[HIS]/.socket.sock`

For hyprctl-like requests. Write `[flag(s)]/command args`.

> [!warning]
> Connections evaluated **synchronously**. Unclosed connections **will freeze Hyprland** until 5-second timeout. Open socket, write, close immediately.

See [[066-configuring-using-hyprctl|Using hyprctl]] for commands.

## Socket 2: `.socket2.sock`

Path: `$XDG_RUNTIME_DIR/hypr/[HIS]/.socket2.sock`

For live events. Hyprland writes: `EVENT>>DATA\n`

Example: `workspace>>2`

## Events

| Event | Description | Data |
|---|---|---|
| workspace | Workspace change (user-requested, not mouse movements) | `WORKSPACENAME` |
| workspacev2 | Workspace change | `WORKSPACEID,WORKSPACENAME` |
| focusedmon | Active monitor changed | `MONNAME,WORKSPACENAME` |
| focusedmonv2 | Active monitor changed | `MONNAME,WORKSPACEID` |
| activewindow | Active window changed | `WINDOWCLASS,WINDOWTITLE` |
| activewindowv2 | Active window changed | `WINDOWADDRESS` |
| fullscreen | Window fullscreen status changed | `0/1` |
| monitorremoved | Monitor disconnected | `MONITORNAME` |
| monitorremovedv2 | Monitor disconnected | `MONITORID,MONITORNAME,MONITORDESCRIPTION` |
| monitoradded | Monitor connected | `MONITORNAME` |
| monitoraddedv2 | Monitor connected | `MONITORID,MONITORNAME,MONITORDESCRIPTION` |
| createworkspace | Workspace created | `WORKSPACENAME` |
| createworkspacev2 | Workspace created | `WORKSPACEID,WORKSPACENAME` |
| destroyworkspace | Workspace destroyed | `WORKSPACENAME` |
| destroyworkspacev2 | Workspace destroyed | `WORKSPACEID,WORKSPACENAME` |
| moveworkspace | Workspace moved to different monitor | `WORKSPACENAME,MONNAME` |
| moveworkspacev2 | Workspace moved | `WORKSPACEID,WORKSPACENAME,MONNAME` |
| renameworkspace | Workspace renamed | `WORKSPACEID,NEWNAME` |
| activespecial | Special workspace changed | `WORKSPACENAME,MONNAME` |
| activespecialv2 | Special workspace changed | `WORKSPACEID,WORKSPACENAME,MONNAME` |
| activelayout | Layout change | `KEYBOARDNAME,LAYOUTNAME` |
| openwindow | Window opened | `WINDOWADDRESS,WORKSPACENAME,WINDOWCLASS,WINDOWTITLE` |
| closewindow | Window closed | `WINDOWADDRESS` |
| kill | Window killed via `hyprctl kill` | `WINDOWADDRESS` |
| movewindow | Window moved to workspace | `WINDOWADDRESS,WORKSPACENAME` |
| movewindowv2 | Window moved | `WINDOWADDRESS,WORKSPACEID,WORKSPACENAME` |
| openlayer | LayerSurface mapped | `NAMESPACE` |
| closelayer | LayerSurface unmapped | `NAMESPACE` |
| submap | Keybind submap changed (empty = default) | `SUBMAPNAME` |
| changefloatingmode | Window floating mode changed | `WINDOWADDRESS,FLOATING` (0/1) |
| urgent | Window requests urgent state | `WINDOWADDRESS` |
| screencast | Screencopy state changed | `STATE,OWNER` (0/1, monitor/window/region) |
| screencastv2 | Screencopy state changed | `STATE,OWNER,NAME` |
| windowtitle | Window title changed | `WINDOWADDRESS` |
| windowtitlev2 | Window title changed | `WINDOWADDRESS,WINDOWTITLE` |
| togglegroup | `togglegroup` used | `0/1,HINDOWADDRESS(ES)` |
| moveintogroup | Window merged into group | `WINDOWADDRESS` |
| moveoutofgroup | Window removed from group | `WINDOWADDRESS` |
| ignoregrouplock | `ignoregrouplock` toggled | `0/1` |
| lockgroups | `lockgroups` toggled | `0/1` |
| configreloaded | Config reload complete | empty |
| pin | Window pinned/unpinned | `WINDOWADDRESS,PINSTATE` |
| minimized | Window minimized by external app | `WINDOWADDRESS,0/1` |
| bell | App rang system bell via `xdg-system-bell-v1` | `WINDOWADDRESS` (may be empty) |

> [!warning]
> Fullscreen events not guaranteed to fire on/off once. Some windows may fire multiple requests, causing multiple events.

## Bash Script Example (socket2)

```sh
#!/bin/sh
handle() {
  case $1 in
    monitoradded*) do_something ;;
    focusedmon*) do_something_else ;;
  esac
}
socat -U - UNIX-CONNECT:$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock | while read -r line; do handle "$line"; done
```

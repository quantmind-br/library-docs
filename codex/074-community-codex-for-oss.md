# Codex for Open Source

The Codex Open Source Fund ($1 million) supports projects that need API credits, including teams using Codex for GitHub PR workflows.

Eligible maintainers receive:
- Six months of ChatGPT Pro with Codex
- Conditional access to Codex Security for core maintainers with write access
- API credits for projects using Codex in PR review, maintainer automation, release workflows, or other core OSS work

Codex Security access is reviewed case by case given GPT-5.4 capabilities.

Core maintainers or widely used public project owners should apply. Projects that don't fit criteria but play an important ecosystem role should apply anyway and explain why.

By submitting, you agree to the [Codex for Open Source Program Terms](https://developers.openai.com/codex/codex-for-oss-terms).

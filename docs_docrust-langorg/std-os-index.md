OS-specific functionality.

[darwin](https://doc.rust-lang.org/std/os/darwin/index.html "mod std::os::darwin")Apple

Platform-specific extensions to `std` for Darwin / Apple platforms.

[fd](https://doc.rust-lang.org/std/os/fd/index.html "mod std::os::fd")Unix or HermitCore or `target_os=trusty` or WASI or `target_os=motor`

Owned and borrowed Unix-like file descriptors.

[linux](https://doc.rust-lang.org/std/os/linux/index.html "mod std::os::linux")Linux

Linux-specific definitions.

[raw](https://doc.rust-lang.org/std/os/raw/index.html "mod std::os::raw")

Compatibility module for C platform-specific types. Use [`core::ffi`](https://doc.rust-lang.org/core/ffi/index.html "mod core::ffi") instead.

[unix](https://doc.rust-lang.org/std/os/unix/index.html "mod std::os::unix")Unix

Platform-specific extensions to `std` for Unix platforms.

[wasi](https://doc.rust-lang.org/std/os/wasi/index.html "mod std::os::wasi")WASI

Platform-specific extensions to `std` for the WebAssembly System Interface (WASI).

[wasip2](https://doc.rust-lang.org/std/os/wasip2/index.html "mod std::os::wasip2")WASI and `target_env=p2`

Platform-specific extensions to `std` for Preview 2 of the WebAssembly System Interface (WASI).

[windows](https://doc.rust-lang.org/std/os/windows/index.html "mod std::os::windows")Windows

Platform-specific extensions to `std` for Windows.

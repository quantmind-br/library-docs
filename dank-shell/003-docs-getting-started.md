# Getting Started

The installer adds the appropriate repository (AUR, COPR, OBS, or PPA) for your distro; updates are managed through your normal package manager.

> [!tip]
> If you install DMS directly from packages, run [`dms setup`](https://danklinux.com/docs/dankmaterialshell/cli-setup) to generate starter compositor and terminal configs (niri/Hyprland only). Deploy individual configs with `dms setup binds` or `dms setup colors`. Other compositors (sway, MangoWC, labwc, Miracle WM) are supported—see [[009-docs-dankmaterialshell-installation#post-install|manual configuration]].

Manual installation is also supported. See the installation section for each component.

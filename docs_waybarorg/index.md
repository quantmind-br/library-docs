## Waybar The Ultimate Customizable Status Bar for Linux Desktops

Simplify your Linux desktop with a fast, modular status bar. Fully compatible with Sway and Hyprland, Waybar helps you organize and customize your workflow.

![](https://waybar.org/wp-content/uploads/2025/10/hero-waybar-1024x576.jpg)

## What Is Waybar?

Waybar is a fast, customizable status bar for Wayland desktops like Hyprland and Sway. It shows key info like workspaces, battery, network, and volume in one place.

Users control everything through the Waybar config file, adding modules, scripts, or custom commands. Lightweight and easy to set up, Waybar works for both beginners and advanced users who want a clean, efficient desktop.

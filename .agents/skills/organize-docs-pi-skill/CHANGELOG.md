# organize-docs-skill — Skill evolution log

This file tracks changes made through the skill's continuous-improvement loop
(see `SKILL.md` → "Improving the skill from real-world use"). Each entry is
one line:

```
- YYYY-MM-DD — <one-line summary>. Found via <folder name>.
```

Routine refactors and pre-loop edits live in `git log`, not here. The
CHANGELOG only captures changes that came from a real-folder run via the
proposal/approval gate.

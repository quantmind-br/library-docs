# Codex

OpenAI's coding agent for software development. Included with ChatGPT Plus, Pro, Business, Edu, and Enterprise plans.

| Capability | Description |
|------------|-------------|
| **Write code** | Generate code matching your intent, adapting to project structure and conventions |
| **Understand codebases** | Read and explain complex or legacy code |
| **Review code** | Identify bugs, logic errors, and unhandled edge cases |
| **Debug and fix** | Trace failures, diagnose root causes, suggest targeted fixes |
| **Automate tasks** | Run repetitive workflows: refactoring, testing, migrations, setup |

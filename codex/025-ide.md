# Codex IDE extension

Use Codex side by side in your IDE or delegate tasks to Codex Cloud.

> [!info]
> Included with ChatGPT Plus, Pro, Business, Edu, and Enterprise. See [[075-pricing|what's included]].

## Extension setup

Works with VS Code forks like Cursor and Windsurf.

| IDE | Install |
|-----|---------|
| Visual Studio Code | [Marketplace](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt) or `vscode:extension/openai.chatgpt` |
| Cursor | `cursor:extension/openai.chatgpt` |
| Windsurf | `windsurf:extension/openai.chatgpt` |
| VS Code Insiders | [Marketplace](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt) |
| JetBrains IDEs | See [JetBrains section](#jetbrains-ide-integration) below |

Available on macOS, Windows, and Linux. On Windows, run natively with the Windows sandbox, or use WSL2 for Linux-native environment. See [[038-windows|Windows setup guide]].

After installation, Codex appears in your editor sidebar (right sidebar by default in VS Code). Restart if you don't see it.

In Cursor, the activity bar displays horizontally by default. Pin Codex and reorganize extension order if collapsed items hide it.

## JetBrains IDE integration

Install the JetBrains integration for Rider, IntelliJ, PyCharm, or WebStorm. Supports ChatGPT sign-in, API key, or JetBrains AI subscription.

[Install Codex for JetBrains IDEs](https://blog.jetbrains.com/ai/2026/01/codex-in-jetbrains-ides/)

### Move Codex to the right sidebar

VS Code: Codex appears in the right sidebar automatically. Drag to the left activity bar if preferred.

VS Code forks (Cursor): may need to move manually.
1. Open editor settings, search for `activity bar` (Workbench settings).
2. Change orientation to `vertical`.
3. Restart editor.
4. Drag Codex icon to the right sidebar (e.g., next to Cursor chat).
5. Reset activity bar orientation to `horizontal`.

You can drag Codex back to the left sidebar at any time.

### Sign in

Prompts to sign in with ChatGPT account or API key after installation. Your ChatGPT plan includes usage credits.

### Update the extension

Updates automatically. Check the extension page in your IDE for manual updates.

### Keyboard shortcuts

Select settings icon in Codex chat > **Keyboard shortcuts**, or see [[068-ide-commands|Codex IDE extension commands]]. For slash commands, see [[069-ide-slash-commands|Codex IDE extension slash commands]].

New to Codex? Read [[029-learn-best-practices|best practices guide]].

## Work with the Codex IDE extension

| Feature | Description |
|---------|-------------|
| Prompt with editor context | Use open files, selections, and `@file` references for shorter, more relevant prompts |
| Switch models | Default or others to leverage respective strengths |
| Adjust reasoning effort | `low`, `medium`, or `high` — trade off speed and depth |
| Image generation | Generate or edit images without leaving the editor |
| Choose approval mode | `Chat`, `Agent`, or `Agent (Full Access)` |
| Delegate to the cloud | Offload longer jobs to cloud environment |
| Follow up on cloud work | Preview changes, ask follow-ups, apply diffs locally |
| IDE extension commands | Full list from command palette, bindable to shortcuts |
| Slash commands | Control behavior and change settings from chat |
| Extension settings | Tune models, approvals, and other defaults |

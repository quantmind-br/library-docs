# Governance

Enterprise teams get visibility into adoption and impact, plus auditability for security and compliance programs.

| Tool | Best for |
|------|----------|
| **Analytics Dashboard** | Self-serve monitoring, quick answers |
| **Analytics API** | Automated reporting, BI integration |
| **Compliance API** | Audit exports, investigations |

## Analytics Dashboard

[Analytics dashboard](https://chatgpt.com/codex/settings/analytics) for ChatGPT workspace administrators to track feature adoption.

### Dashboards

- Daily users by product (CLI, IDE, cloud, Code Review)
- Daily code review users / reviews
- Code reviews by priority level
- Daily code reviews by feedback sentiment
- Daily cloud tasks / users
- Daily VS Code extension users
- Daily CLI users

### Data export

Export in CSV or JSON:
- Code review users and reviews (daily unique users, total reviews)
- Code review findings and feedback (comments, reactions, replies, priority-level findings)
- Cloud users and tasks (daily unique users, tasks completed)
- CLI and VS Code users (daily unique users)
- Sessions and messages per user (daily session starts, user message counts across surfaces)

## Analytics API

Automate reporting, build internal dashboards, or join Codex metrics with existing engineering data.

### What it measures

Daily, time-series metrics for a workspace, with optional per-user breakdowns and per-client usage.

### Endpoints

**Daily usage and adoption**
- Daily totals for threads, turns, credits
- Breakdown by client surface
- Optional per-user reporting

**Code review activity**
- PR reviews completed by Codex
- Total comments generated by Codex
- Severity breakdown of comments

**User engagement with code review**
- Replies to Codex comments
- Reactions (upvotes, downvotes)
- Engagement breakdowns for team response to Codex feedback

### How it works

Daily and time-windowed. Results are time-ordered, returned in pages with cursor-based pagination. Query by workspace; optionally group by user or aggregate at workspace level.

### Common use cases

- Engineering observability dashboards
- Adoption reporting for leadership updates
- Usage governance and cost monitoring

## Compliance API

Export detailed activity logs for audit, monitoring, and investigations. Designed for eDiscovery, DLP, SIEM, and other compliance systems.

### What it measures

Export logs and metadata for Codex activity to connect to existing audit, monitoring, and security workflows.

For ChatGPT-authenticated usage, Compliance API exports provide audit records retained for up to 30 days. API-key-authenticated usage follows API organization settings and is **not** included in Compliance API exports.

### What you can export

**Activity logs**
- Prompt text sent to Codex
- Responses generated
- Identifiers: workspace, user, timestamp, model
- Token usage and request metadata

**Metadata for audit and investigation**
- Who ran a task
- When it ran
- Which model was used
- How much content was processed

### Common use cases

- Security investigations
- Compliance reporting
- Policy enforcement audits
- Routing events into SIEM and eDiscovery pipelines

### What it does not provide

- Lines of code generated (noisy proxy for productivity; can incentivize wrong behavior)
- Acceptance rate of suggestions (almost 100% since users usually accept changes first)
- Code quality or performance KPIs

## Recommended pattern

Most enterprises use a combination of:
1. **Analytics Dashboard** for self-serve monitoring and quick answers
2. **Analytics API** for automated reporting and BI integration
3. **Compliance API** for audit exports and investigations

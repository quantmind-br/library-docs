## Overview

Quit warning prompts confirmation before closing with running processes, preventing unintended data loss.

## Enabling

- **Settings** → **Features** → **General** → toggle "Show warning before quitting".
- Or via [[104-terminal-command-palette|Command Palette]] → search "Quit Warning".

## Quit Warning Modal Options

| Option | Action |
|--------|--------|
| Yes, quit | Closes all Warp sessions and processes |
| Show running processes | Opens [[118-terminal-sessions-session-navigation|Session Navigation]] with running process filter |
| Cancel | Prevents Warp from closing |
| Don't ask again | Disables the quit warning feature |

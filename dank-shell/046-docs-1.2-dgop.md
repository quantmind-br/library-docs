# DGOP

`dgop` (Dank GO Process Status) is a stateless system and process monitoring tool providing a top-like TUI, CLI, and REST API.

![DGOP TUI](https://danklinux.com/img/dgoplight.png)

## Features

- top-like TUI
- CPU, GPU, Memory, Process, Network, Disk metrics
- Cursor-based stateless sampling over any time period
- OpenAPI 3.1 REST API
- CLI for human-readable or machine-readable output
- `meta` call to mix and match metrics

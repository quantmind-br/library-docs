# Create Embeddings

Generate embedding vectors representing input text using a specified model.

## Endpoint

```
POST /v1/accounts/{account_id}/embeddings
```

## Authorizations

| Type | Location | Description |
|------|----------|-------------|
| Bearer | `Authorization` header | Fireworks API key. Format: `Bearer <token>` |

## Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `input` | string or array | Yes | Text to embed. Can be a single string or array of strings. Each input must not exceed the model's max tokens (e.g., 8192 for `nomic-ai/nomic-embed-text-v1.5`). Cannot be empty. Max 2048 dimensions for arrays. |
| `model` | string | Yes | Model to use for embedding. Example: `"nomic-ai/nomic-embed-text-v1.5"` |
| `prompt_template` | string | No | Jinja2 template for processing input before embedding. Fields from input objects substituted via `{field_name}`. Exposes `truncate_tokens(string)` function. Example: `"Embed this text: {text}"` |
| `dimensions` | integer | No | Number of output dimensions. Only supported in `nomic-ai/nomic-embed-text-v1.5` and later. Range: `x >= 1` |
| `return_logits` | array | No | Return raw model logits for specified token/class indices. Empty list returns all logits. Only specified indices returned otherwise. Softmax applied to selected tokens when used with `normalize=true`. |
| `normalize` | boolean | No | Normalize output. Without `return_logits`: L2 normalization (unit vectors). With `return_logits`: softmax applied to create probability distributions. |

## Response

| Field | Type | Description |
|-------|------|-------------|
| `data` | array | List of embeddings generated by the model |
| `model` | string | Name of the model used |
| `object` | string | Always `"list"` |
| `usage` | object | Usage information for the request |

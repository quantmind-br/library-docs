Warp provides two assisted input features: completions and autosuggestions.

1. **[[099-terminal-command-completions-completions]]** — fuzzy suggestions for commands, options, and path parameters.
2. **Autosuggestions** — automatic command suggestions as you type, based on shell history and possible completions.

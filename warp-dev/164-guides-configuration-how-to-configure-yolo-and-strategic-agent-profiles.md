## Agent Profiles Overview

Warp supports two agent profiles that control how agents approach tasks:

- **YOLO Mode** — Agents act quickly with minimal hesitation, suitable for straightforward tasks where speed is prioritized.
- **Strategic Mode** — Agents plan thoroughly before acting, suitable for complex tasks requiring careful consideration.

## Configuration

Configure the agent profile in your environment or via CLI flags when running an agent.

> [!note]
> Profile selection affects agent behavior, response latency, and decision-making depth.
